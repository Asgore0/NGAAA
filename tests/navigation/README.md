# 导航恢复回归

运行 `bash tests/navigation/run.sh`，需要 JDK17，无 Android 模拟器、网络或账号依赖。测试执行实际 NavigationState 编解码和校验，覆盖版块→帖子→图片的完整返回次序、编辑目标、搜索范围、页码/偏移、32 层上限、坏类型/坏字段过滤、媒体来源和授权数据不能进入路由字段。

MainActivity 以固定列字符串数组写入私有 Bundle schema，不序列化 Topic、帖子/私信正文、Cookie 或二维码。每条只含页面标识、必要参数、有限标题和偏移；不依赖动态控件自动状态恢复。图片路由还须符合 NativeImages 的允许来源及 attachments 路径。纯 JVM 回归不代替设备旋转和返回操作验收。

显式保存的登录页始终恢复，不以设备上保留的旧账号推断本次授权完成；无页面快照但有加密待恢复授权时回到原生登录页。位置为 `-1` 表示保存时滚动容器尚未出现；已有位置（包括 `0`）优先于帖子的首次楼层定位。实际图片布局变化仍可能改变像素位置。

`HomeScreenStateTest` 另覆盖评分分类与页码、版块分类与筛选、列表首行及相对内边距偏移的有界恢复。主页状态在导航键重建前恢复，避免折叠或旋转后把旧评分位置应用到默认分类；保存时读取当前列表首行，而不依赖先离开页面。错误类型、超长文本、控制字符和越界数字会回到默认状态。实际旋转、折叠和返回操作仍由模拟器验收。
