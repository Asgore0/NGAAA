# Native thread action offline regression

Run `tests/thread_actions/run.sh` from any directory. The test verifies the pinned test-only JSON dependency and strictly compiles the production API with an offline NgaStore and fake transport. No response is fetched and no account or post is mutated.

209 protocol assertions and 18 Android-style journal commit assertions cover official reaction toggle flags, separate net-score semantics, old envelopes and GB18030, fixed origin headers, account/route changes, confirmation-bound sessions and single-use drafts, durable unknown-write protection across reopened sheets/API instances, duplicate in-flight taps, report reasons/read-vs-submit separation, exact report form, ordinary and grouped polls, private results, expired polls, foreign choices, copper bet amounts, and invalid data boundaries.

Fixtures are synthetic representations of the downloaded official JavaScript contract. They prove request/parser/state handling, not real server acceptance. Production UI still requires explicit native button confirmation for every mutation; never test real reporting or voting automatically.

The 0.20.14 regressions cover the official `raw=3` HTML data envelope, absent optional acknowledgement text, zero state flags, rejection of additional scripts, and explicit local recovery after an uncertain reaction. Recovery clears only the confirmed account/post guard; a new server submission still requires a separate confirmation. No actual account session or captured authenticated response is a fixture.
