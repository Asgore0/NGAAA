# 首帖图片元数据与缓存离线验证

运行 `bash tests/topic_previews/run.sh`，只需本机 Java 17，不下载依赖，不连接网络、不访问账号或 Android 存储。

163 项断言覆盖：

- 首帖最多 3 张、稳定去重的官方 attachments 图片；旧 HTTP 升级为 HTTPS、可信相对附件与日期校验。
- 引用（含带参数和嵌套形式）、代码、crypt、隐藏/购买、折叠 collapse/spoiler 内容排除；表情、头像、编辑封面、非可信域名、SVG、查询参数、片段和路径穿越不成为缩略图。
- 单个正文至多 256 KiB；长畸形标签扫描有界；返回快照不可修改。
- 以 64 位账号/域名会话摘要和 tid 为键的内存缓存：96 条 LRU，正图 30 分钟，无图 5 分钟，失败 30 秒；不保存 Cookie、正文、图片字节或磁盘数据。
- 仅由 UI 可见且停稳的行触发请求；数据调度器最多 2 个并发、12 个排队，同图同帖请求共享；队列满时明确回调失败，避免永久等待。
- 回收一行不会取消另一个订阅者；最后一个订阅者离开后中断工作线程并主动断开追踪的 HTTP 连接；取消后的结果不写缓存、不回调旧行；缓存命中的延迟回调同样受取消约束。
- 已读首楼 seed 抢占旧请求；显式刷新 invalidate 仅删除当前 scope 缓存、取消视图在途请求；其它 scope 的既有元数据保留。

`tests/api/run.sh` 另外用原生响应结构验证 tid、页码、明确首楼与作者边界；`tests/reliability/run.sh` 使用完全隔离的 URL 连接验证身份捕获和唯一原生请求，不发真实 HTTP。

这些测试验证提取/身份/队列/缓存逻辑；不代表线上所有图片可用，也不测实际 UI 滚动或图片解码帧率。

取消夹具分别建模两种真实网络行为：忽略线程中断的 socket 必须由 `NgaReadCancel` 守护线程主动断开；可中断响应必须执行与 NgaApi 一致的 `finally` 连接释放。前者保留原 5 秒总截止，不因中断重置截止；两者都验证取消后不缓存、不回调。旧夹具把可中断 await 与仅异步清理混在一起，遗漏真实 API 的 finally disconnect，会在关闭 registration 后移除尚未执行的异步动作；该竞态的首轮失败证据保留在开发验证记录。
