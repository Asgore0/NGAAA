## 界面与交互

提示、选择、搜索/版块输入、发布确认、附件确认、编辑预览和私信窗口使用共享原生玻璃组件。安全验证码只统一外层标题、说明与取消按钮；腾讯官方验证内容、隔离 WebView、JS 桥和结果处理保持原逻辑。

面板使用圆角玻璃材质、独立标题和关闭按钮，正文可滚动，底部操作区留在滚动区域外。最大宽度 480dp，展开窗口居中；按键盘可见区域限高。明确设置深色文字、输入框、勾选项和禁用按钮颜色，实色及关闭动画设置继续生效。

默认确认动作先关闭并同步清理，再执行业务回调。输入校验或发送中锁窗由调用方控制；无效输入保留窗口。程序关闭与 Activity 销毁会中止待执行的退出动作；安全验证码取消立即生效，迟到成功不能取代取消结果。
