## 胶囊模型与实际输入

模型使用与View相同的纯Java核心，已纳入本轮最终离线回归：20类连续性场景、25211项检查，以及12条拖动轨迹、6次松手、2次停住的2130项响应检查通过。输入间隔8/16 ms与绘制间隔8/16/33 ms交叉重放；相对0.12.0同轨迹模型，慢拖视觉中心平均误差下降约72–78%，快速反向平均误差下降约50–66%，p95下降约64–73%。松手轮廓收敛阈值由561–594 ms缩短到296–330 ms。这是确定性模型结果，不是模拟器或真机延迟、固定帧率承诺。

中心误差为绘制中心与合成手指位置之差，一个标签单元格为1 cell；前96 ms不计入。松手收敛要求中心误差小于0.012 cell、拉伸小于1.018倍、高度误差小于0.008、前后端速度均小于0.12 cell/s，且持续满足。突然停住但不松手时，模型允许约0.126 cell的短暂液态余量，约300 ms后中心误差小于0.002 cell，无需等新MOVE恢复。

实际API35模拟器分别安装发布的0.12.0原包和候选0.13.0，完成相同4个公共输入轨迹。受测APK字节、相同驱动、同一boot和单元格几何均已绑定。驱动记录真实注入uptime，原生轨迹记录Choreographer时间及绘制边缘；无需拟合偏移即可直接重叠。组件宽度由像素宽度与归一化边缘恢复，以首页静止中心和RadioButton单元格宽度为基准，对实际注入触点线性插值。指标为原生帧几何，不含屏幕实际呈现或物理触控延迟。

## 版块图标与作者头像

官方原图研究在373个原有唯一fid中核验352个，旧映射97个，新增255个覆盖；仍有21个未获得可靠原图。536张原PNG共5564742字节，其中352张用于fid版块，184张为独立合集资产。设备已核验生产页全部352个fid映射，并用每批最多16张、共34批的有界队列解码536张本地PNG，失败0、网络请求0。可见性取消、重绑迟到回调和24任务上限的繁忙重试也通过；40个可见合成头像在饱和后均恢复。当前目录按fid去重，合集身份与路由尚未接入，不能将184张资产计作当前可见列表覆盖。只接受精确官方URL映射，缺失时回退到CDN或文字占位；研究下载未使用Cookie。

头像补充官方候选列表、编码分隔符和紧凑地址，避免空用户表覆盖同响应已有头像。仅真实可见视图订阅；离屏、隐藏、重绑和分离会取消，队列繁忙重试。同UID共享查询和内存缓存，匿名或负数ID不查询；通用加载器和合成探针默认不启用作者资料来源。

真实排查发现：有头像的公开楼层作者，在正常已登录原生资料页也能显示照片；但初期无Cookie查询的4名正数公开作者全部返回空头像字段。因此无Cookie空结果不能证明用户没有设置头像。主Activity现在捕获当前会话快照，登录态使用 `sessionSource(host,cookie,stillCurrent)` 补齐作者头像，仅向 `bbs.nga.cn`、`ngabbs.com`、`nga.178.com` 中当前同一受信站点发送既有Cookie，不跟随重定向。开始、响应、读取和结束均检查host与Cookie仍相同；内容范围变化时重建解析器，取消旧任务与缓存。未登录使用无Cookie公开来源。CDN图片和本地图标读取不携带会话Cookie。

资料来源只提取匹配UID的头像字段，不保留用户名、资料其他字段或响应正文，不持久化资料。来源边界新增54项fixture检查，解析器合计298项，已纳入最终17组离线回归，无真实网络请求。`AvatarLiveProbe` 已在真实生产Activity来源上验证：选择公开楼层中3名已知有真实头像的正常作者，以全新元数据/图片缓存和可见 `bindUser(uid,空元数据)` 绑定，3/3均补齐并解码真实照片，剩余占位0，默认图或不匹配结果计数0；没有本地头像mock或来源包装器。未截图、未记录作者身份或照片、未执行远端写入，恢复原页面后账号与设置保持一致。

服务器仍未返回可用个人头像时显示官方通用头盔，辅助文字标记“默认头像”；它不是个人头像，也不计入真实头像覆盖。登录态补齐是本次头像缺失的主要修复，默认图仅作后备。上述3名作者的真实补齐通过，不保证所有作者都有可用个人头像。
