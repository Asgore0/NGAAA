## 正文与签名

公开活动帖 [47190819](https://bbs.nga.cn/read.php?tid=47190819) 的真实首楼使用 `[jumpurl][url]活动URL[/url][/jumpurl]`，随后为官方原图附件。新增精确回归确认：活动只生成一个完整链接、没有原始jumpurl/url标签，原图和独立图片查看入口仍保留。带格式的链接标题、多层链接及交叉闭合也纳入回归，避免嵌套多个点击锚点。

| 标签家族 | 本版行为 |
| --- | --- |
| `jumpurl`、`url`、官方内部引用及@用户 | 安全目标形成链接，保留标题样式；无效目标不形成可执行链接 |
| `code=语言` | 与无参code一致，原样保留代码中的标签、缩进和换行 |
| 官方img数字变体、旧HTTP图片 | 受信附件按原生图片流程显示；仅精确官方图片主机升级HTTPS；外部图片保留可点文字，不自动抓取 |
| 列表、上下标、字体、标题、左右排版、色彩与尺寸 | 支持常见官方语法及空格参数，跨引用和折叠块保留内联样式 |
| table/tr/td | 转为带行列分隔的原生流式内容，保留单元文字和内部样式 |
| 相册、附件、flash/media、iframe | 安全图片沿用原生媒体流程，其余媒体提供可读名称和合法目标链接，不执行Flash或任意iframe |
| style/fixsize、headline/randomblock、成就等已知包装 | 保留可读正文，按手机宽度重新排版，不复制任意CSS、随机选择或网页轮播行为 |
| dice、crypt、Spine | 保留骰子表达式并提示官方结果；加密和Spine显示官方页面提示，不伪造解密、随机结果或执行动画载荷 |

未知标签、普通 `[文本]` 和不完整标签保留原文，代码块先于包装处理，不通过全局正则删除方括号。旧签名专用剥标签逻辑改为共享 `PostRenderer.plainText()`，避免签名与正文支持范围不一致。原生链接保留URLSpan语义，点击仍进入客户端统一路由。

语法核对使用公开官方 [BBCode core](https://img4.nga.cn/common_res/js_bbscode_core.js?1342409)，原始文件SHA256为 `90ef6ebbf7bbc688610ff132beaf1893d07bcdbdfd52fa801f1dea1f906d13de`；jumpurl的实际嵌套形态另由上述公开活动帖确认。

## 链接去向

普通帖子、版块和按UID引用的用户继续进入对应原生界面。活动网页、合集、只看某作者、搜索条件、未知锚点等需要保留原始语义时，显示完整URL供用户确认，再交给系统浏览器。不会静默丢弃参数后打开一个看似相同的普通列表。只含PID而没有可用TID的官方链接也保留浏览器解析语义，不虚构主题ID。

`BrowserLinks` 只构建HTTP(S)浏览器Intent，不附加应用Cookie、请求头或登录数据；浏览器类别选择排除客户端自己的深链解析，避免反复打开客户端。浏览器自身已有的登录态由浏览器管理。客户端内置图片查看只接收合法栅格附件，视频、PDF和普通网页进入相应浏览器流程。
