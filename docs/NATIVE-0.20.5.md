# NGAAA 0.20.5 · 板块目录性能

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

目录的一次数据更新共享不可变的会话摘要、收藏与同步状态。绘制每张卡片时只读取该快照，减少主线程重复访问 Android Keystore 和解析收藏状态的次数。快照不保存 Cookie 或其他凭据；实际点击卡片、收藏和长按操作继续检查当前会话与页面代次。

首次布局等待实际可用宽度后再创建列表，避免先创建单列、随即丢弃重建多列。窗口宽度或字号变化时重排已筛选的数据，保留按版块标识恢复滚动位置的行为。收藏同步事件更新正在显示及后续回收复用的星标。

保留 0.20.4 的暖白、石墨与低饱和金色，以及现有玻璃背景和胶囊动画。实测数据、验证范围及录像见同版本报告；模拟器测量不代表所有实体设备的帧率。

帖子列表、推荐、搜索、收藏与历史的预览区移除点赞、点踩及其计数，保留回复数和右侧时间。窄屏大字号时两行排布，详情页原有点赞点踩操作保留。
