# Android 0.19.7 日常功能更新

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

版本 `0.19.7 / versionCode31`，包名 `cn.ngapure.app`，最低 API26，目标 API35。基于已发布的 0.19.6 补充原生日常操作。累计功能和第三方内容边界见 README，实际候选产物及测试结果见随包验证报告。

## 继续阅读与本地列表

- 成功加载的普通帖子在离开页面或暂停应用时保存页码及可用的楼层锚点。只看楼主的过滤分页不覆盖普通阅读进度，失败或仍在加载的页面不冒充已读。
- 正常重新打开帖子时恢复已有进度；历史和本地收藏显示读到的页码与楼层。长按可以继续、从头读、移除单条或复制帖子链接；帖子菜单也有从头阅读入口。
- 历史及本地收藏支持按标题、作者和版块筛选，清空需要明确确认。清空本地收藏不更改云端收藏；清空历史会同时移除当前账号和域名下的阅读位置。
- 设置可暂停记录。暂停后不记新的历史或阅读位置，已有记录仍可查看和继续。
- 历史最多100条，本地收藏最多300条，持久进度全局最多128条。进度和搜索关键词以论坛域名及账号身份摘要隔离，重新授权同一账号不会因 Cookie 改变而丢失；读写回调仍以精确会话校验。
- 位置写入使用有界进程内后台队列，不在滚动的每一帧写盘。突然强制终止进程或存储失败时，最后一次尚未写入的位置可能无法恢复；不保存离线正文。

## 搜索和系统入口

- Android `text/plain` 系统分享和用户点按的粘贴按钮可从“标题加链接”的文字中提取官方只读目标；不会在启动或回到前台时自动读取剪贴板。
- 分享输入最多16KiB，最多提供8个不同目标，多链接使用原生选择弹窗。伪域、登录、编辑及写操作链接不会通过这个入口执行。
- 搜索弹窗明确提供全站/当前版块范围，结果页再次搜索会保留关键词和范围。未提交输入及范围可在同一页面和会话内随窗口重建恢复。
- 最近搜索最多12个已提交的有效关键词，支持填入、单条删除和清空。不记录分享链接、用户名查询、未提交文字或明显登录凭据。
- 搜索快捷入口与弹窗次要按钮按实际可用宽度和文字大小自动横排或纵排，窄屏及大字体不会把后面的按钮压成单字长列。
- 版块页和搜索弹窗可通过合法正负版块编号、`stid:合集编号` 或 NGA 版块链接进入；不把0或无效输入当成有效版块。

## 阅读操作和缓存

- 楼层操作提供复制干净正文、原始代码、楼层链接及系统分享；有效 PID 使用准确定位链接，没有可用 PID 时带上当前页码。
- 干净正文复用现有正文解析器，不向剪贴板直接复制 BBCode 标签；加密正文不会被这一操作悄悄解密。
- 帖子菜单提供字号选择和即时预览，应用后尽量保留当前楼层。
- 设置中显示图片文件和内存缓存占用，可清理受管理的图片、头像和表情文件。账号、草稿、本地/云端收藏、历史及提交日志不属于这项清理范围。
- 清理只移除本缓存的受控普通文件，不进入未知目录或跟随符号链接。清理前的旧下载/解码任务仍可交付当前页面，但不能再把旧内容写回已经清理的缓存；当前可见 Bitmap 不会被回收。
- 原缓存上限仍为内存8MiB、磁盘32MiB/128项/7天。部分文件清理失败时显示剩余占用并允许重试。

## 验证范围

离线测试覆盖分享解析、搜索历史、进度格式与隔离、持久化失败及并发、缓存清理和原有协议。新增独立 UID、无 INTERNET 权限的 Android 验证器使用原始生产类与本地生成内容，检查真实 Main、窗口重建、系统分享 Intent、实际 PNG/Bitmap 和文件系统行为；不会使用真实账号制造发帖、私信或云端收藏变更。

真实客户端另做只读页面、深色/大字/展开窗口、快速导航和录屏检查。独立测试中的合成成功不代表真实服务器写入端到端验收，模拟器窗口不等于实体折叠屏或实体手机帧率认证。固定玻璃、胶囊动画和既有登录/签到配置继续保持。
