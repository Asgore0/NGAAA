## 本轮重点

精确活动帖47190819首楼为 `[jumpurl][url]https://bbs.nga.cn/misc/event/20261015zmd/index.html[/url][/jumpurl]`，后接官方图片。回归分别确认唯一活动锚点、完整目标、无原始包装标签、原图及独立原生图片查看入口；带标题和更多链接嵌套也只形成一个活动锚点。图片入口本身另有锚点，不能为了“只有一个链接”的统计删除原图交互。

正文与签名共用安全解析器，验证code=语言中的标签、缩进和换行保持原文；未知标签与普通方括号不被误删。列表和表格使用Android可显示的行列分隔，内联字体、上下标、链接和粗体可跨引用及延迟折叠块。相册沿用原生InlineImage流程。

路由回归覆盖正常帖子/版块/用户原生导航，活动和合集浏览器打开，筛选条件、页码、锚点及旧编码语义保留；重复关键参数、危险scheme和写操作目标不会误转成阅读页。设备探针确认浏览器Intent保留完整URL、类别和浏览器选择器，不附加Cookie或请求头；合成探针截获外部启动，另以真实公开原帖点击、确认和返回验证实际系统浏览器启动。
