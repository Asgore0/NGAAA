# 仓库整理说明

本目录从现有原生客户端工程整理而来。保留 `app/`、公开板块目录与图标、`tests/` 合成/公开协议夹具、Markdown 说明、构建配置和第三方来源声明。版本号为 **0.20.13（47）**；冻结候选 c8 已于 2026-10-25 通过本地预设的三轮性能门槛，范围见 [版本说明](NATIVE-0.20.13.md)。安装包与云端构建状态分别以仓库 Releases 和 Actions 的实际记录为准。

未收入源码仓库：APK/JAR/DEX/CLASS/ZIP、SDK、`.build`、Gradle 缓存、签名密钥、工作目录、原始设备报告、历史截图/录屏、账号私有数据和真实授权记录。历史 Markdown 中指向这些附件的链接被改成说明；相关原始证据仍归各历史版本，不是本仓库的新验收结果。

整理改动限定于构建与说明：

- SDK 构建支持显式 Linux/macOS 环境，产物放 `dist/`，中间文件放 `.build/app/`。
- 签名默认放用户数据目录，并拒绝仓库内密钥；支持外置自有签名环境变量。
- 提供统一测试环境入口与固定 SHA 的测试依赖，旧测试的生产逻辑、用例和 fixture 保留。
- 两个早期 Android helper 的默认生产类目录改为 `.build/app/`，并要求显式提供外置 `SIGNING_DIR`；不再猜原工作区位置。
- README 明确候选状态，新增文档索引、测试说明和贡献说明；历史文档标注历史归属、修复路径与失效附件引用。
- 第三方声明单列 NGA 目录、图标和默认头像，未改变其权利归属。

应用 Java 源码、Android 资源及业务逻辑未因仓库整理而修改。后续性能修复需单独同步并重新校验版本及依赖。

以下记录保留各次执行时点的结论；“尚未证实提速”指当时尚未完成最终三轮测试，不能替代最后一段的当前状态。
