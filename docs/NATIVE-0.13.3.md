## 界面与交互

原生底部浮层使用圆角玻璃材质、独立标题和关闭按钮。目标页码使用大号数字，可直接输入、前后微调或点击相邻页。帖子从实际ThreadPage取得总页数，提供原生拖动条和首尾入口；版块总数未知时仅显示当前页，保留输入和相邻页选择，不显示虚构总数。

确认按钮在滚动区域外。键盘或短窗口缩小可见高度时，内容可滚动，按钮保持可用。浮层最大宽度480dp，展开窗口居中；深色、1.3倍字号和关闭系统动画的设置分别处理。

无效输入显示原位提示并保留浮层；重复触发IME和确认按钮只提交一次。选择当前页仅关闭，不重载帖子。导航或Activity销毁会关闭面板；提交绑定原页面身份与代次，旧面板不能跳转后来打开的页面。
