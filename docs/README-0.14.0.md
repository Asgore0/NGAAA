## 本地构建

Java17 与 Android SDK API35/build-tools35.0.0 就绪后运行 `bash build-local.sh`。脚本读取 manifest 版本并离线编译、校验和签名，无 Gradle 或外部运行时 JAR。覆盖安装需保留同一本机签名；源码 ZIP 不包含签名密钥。
