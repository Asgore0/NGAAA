# 0.11.0 设备检查

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

设备为本任务专用 API35 模拟器。下表检查在数字分页兼容修复后的最终候选 APK 上复跑，输出固定布尔值和几何计数，不包含账号、私信正文、凭据或媒体地址。APK、生产输入及探针源码的绑定记录见 本版验证 JSON（历史附件未收入源码仓库）。

| 检查 | 结果与实际范围 |
| --- | --- |
| PaginationProbe | Android 原生 JSON 数字键不兼容复现；新解析/引用用户表/赞数分页/表达式拒绝通过；同一首页推荐帖读出20条正文与65页分页 |
| MediaProbe：队列与取消 | 24个媒体请求上限生效；取消移除等待任务；队列拒绝与缓存命中的迟到回调均被抑制 |
| MediaProbe：内存 | 清空加载器缓存后，仍由界面持有的 Bitmap 没有被 recycle |
| MediaProbe：视口 | 未挂载正文不请求图片，仅加载可见附近图片；滚离旧位置或移除正文后取消对应请求 |
| MediaProbe：动画 | 仅自身可见的合成 Animatable Drawable 播放；滚离和移除后停止；不包含真实 GIF/WebP 解码覆盖承诺 |
| MediaProbe：阅读锚点 | 首张图片实际高度从80变为500像素后，同一文字锚点差异0像素 |
| OptimizationProbe：普通帖子 | 新 Activity、新 ScrollView 恢复第2页及用户自选1260像素位置，并可返回首页 |
| OptimizationProbe：PID帖子 | 先定位目标楼层，再主动滚离；重建后保留自选1260像素位置，没有再次强制拉回目标楼层 |
| OptimizationProbe：底栏 | 快速切换待提交时保存与重建，保留实际呈现的标签及其偏移 |
| OptimizationProbe：内存回收 | 触发 trimMemory 后阅读几何保持一致 |
| ReaderProbe | 首次与重复打开同一公开回复均落在正确页面/楼层，旧零偏移没有覆盖新定位；20条净赞、8个头像，8张真实头像均解码 |
| 保留会话 | 真实 `iflogin` 返回 HTTP200、协议码0、verified=true；没有重新扫码或提交密码 |
| 自动签到状态 | 启用、当天确认、Job计划均保留；确认记录来自0.10.0于2026-10-19 00:06:42的打开应用补签，本轮没有清除缓存或重签 |
| 窄屏与展开尺寸 | 单列表不被左栏遮挡、单层底栏、菜单关闭操作可达；测试后恢复原显示参数 |
| 主题与后台返回 | 深色页面实际显示，随后恢复浅色；切到后台再返回，玻璃背景重新生成 |
| 运行日志 | 本轮保留的日志缓冲未出现应用崩溃；不等于所有路径永不崩溃 |

MediaProbe 使用本机合成媒体、工作线程屏障和关闭的加载器，不向网络请求测试图片。公开阅读探针访问 NGA 公开内容；启动前先要求当天签到已确认、没有待恢复授权，避免测试启动顺带执行账号写入。

本轮没有真实密码/SMS正向登录、短信发送、新扫码授权、发布、上传、私信发送或云端收藏变更。窄屏/展开是同一模拟器的临时尺寸变化，不是物理铰链测试；未覆盖低版本运行、Doze、厂商后台和自然24小时无人值守签到。历史记录见 [0.10.0清单](DEVICE-TEST-CHECKLIST-0.10.0.md)，不计作本轮重新执行。

最终发布校验会检查当前 APK、生产/测试源码与实际测试日志 SHA、签名、源码 ZIP 校验和以及历史制品是否保持不变。完整范围见 [验证总览](VALIDATION.md)。
