## 本地构建

Java17与Android SDK API35/build-tools35.0.0就绪后运行 `bash build-local.sh`。脚本读取manifest版本并离线编译、校验和签名，无Gradle或外部运行时JAR。覆盖安装需保留同一本机签名；源码ZIP不包含签名密钥。
