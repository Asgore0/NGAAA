## 实际环境

本轮已运行并核验专用 `emulator-5582 / NgaPureUiV3`，Android Emulator 37.2.12，Android 15 / API 35 Google APIs arm64-v8a rev9，1080×2400 / 420 dpi，headless、2 CPU。保留现有 userdata 和 Keystore，没有 wipe 或复制其他 AVD；实测结束后已正常关闭此专用 VM。

启动请求 1536 MiB RAM，模拟器自动提升至实际 2560 MiB。Guest Vulkan feature disabled，但宿主 ANGLE 仍报告 SwiftShader Vulkan 后端；不能写成实际 1.5 GB 或所有 Vulkan 关闭。

此前有窗口的宿主 QEMU 发生 main-loop hang，宿主报告定位到 Qt accessibility 及 hang detector。切换 headless 后 boot、shell、Binder 和控制台恢复，两轮探活通过。该事件有宿主冻结证据，未将其记作 Android 应用崩溃。

## 连续触点与形变

独立 UiAutomation 工具注入同一 `downTime` 的完整 MotionEvent 流。初始 pointer ID 为 7，多指时加入 ID 11；只有 UP/CANCEL 才结束。外部非阻塞状态采样避免同步截图干扰原始时序。

| 场景 | 最大宽度 | 相对静止宽度 | 最低高度比例 | 已确认行为 |
| --- | --- | --- | --- | --- |
| 慢拖保持 | 322.07 px | 1.382× | 0.890 | 真实持续触点、拉伸和压扁 |
| 快速反向 | 353.93 px | 1.519× | 0.848 | 同一触摸序列反向，结束后稳定归位 |
| 取消 | 370.11 px | 1.588× | 0.889 | CANCEL 直接回到已提交的 index 0 |
| 多指 | 354.06 px | 1.520× | 0.862 | 换指后继续拖动，不误触发首页再次选择 |
| 垂直移动 | 233 px | 1.000× | 1.000 | 不进入横向形变、不误开分组菜单 |
| 未选中项起拖 | 365.65 px | 1.569× | 0.848 | 从 index 2 起拖，头端达到 2.8573 后归 index 3 |

松手 1 秒后，记录的 head/tail 回到目标，静止尺寸为 233×136 px，`animating=false`。这些值属于本设备采样，不是 Apple 公开参数或跨设备固定尺寸。

motion-summary-0.5.0.json（历史附件未收入源码仓库） 中，各持触动作的底图快照计数只有一个不同值：慢拖 25、反向 31、取消 36、多指 36、未选中起拖 41。它们来自不同采样窗口，含义是**各自持触窗口内没有重复捕获底图**，不是不同动作间永远不刷新。局部形变和折射参数更新不依赖全背景逐帧重捕。

内部状态选项在当前环境不可靠，复现时遵照测试 README 使用外部状态采样。同步 PNG 编码会影响短手势；原速验收应关闭同步截图，不将截图造成的中断当作应用手势失败。

## 真实视频与未覆盖边界

已完成 0.5.0 实际操作录屏（历史附件未收入源码仓库）：720×1600，实际时长 16.6036 秒，文件 2,842,784 字节；预览图（历史附件未收入源码仓库） 随交付提供。内容包含慢拖保持、快速反向、跨项切换、临时分组及内容在单层导航后滚动。

本次以独立录屏观察画面，避免逐张同步 PNG 阻塞触摸注入。视频校验记录（历史附件未收入源码仓库） 保留原视频 SHA-256 和检查范围：91 个请求采样对应 60 个不同实际视频时间。交付的 motion-frames.json（历史附件未收入源码仓库） 记录四张实际裁剪帧的请求时间、实际时间和原视频哈希。操作墙钟与视频时间不可直接当作同一时基，重复时间也不算新的独立帧。主代理已结合视频检查这些采样，但这不等于全片逐帧帧率评估或跨设备性能保证。截图索引见 [专项记录](LIQUID-0.5.0.md)。

当前仅 API 35 实测。API 26/31 等低版本、CPU 回退、低内存和厂商真机、完整 TalkBack、横屏/低矮屏幕、长时间内存稳定性及自然跨日 24 小时调度未覆盖。实色开关通过不等于低 API 回退通过。首次全新安装、重新扫码、过期退出、实际发布和上传也不由升级状态推断通过。
