## 本地构建

安装Java17与Android SDK API35/build-tools35.0.0后运行 `bash build-local.sh`。脚本从manifest读取版本，离线编译、zipalign并签名，无Gradle或外部运行时JAR。保留本机签名才能覆盖安装已有开发版；源码ZIP不包含签名密钥。
