# NGAAA 0.19.9 图标与楼主图片预览

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

版本0.19.9，versionCode33，包名cn.ngapure.app，沿用0.19.8签名和本地数据。Android8/API26起可用，目标API35。

## 图标

冰蓝色背景、蓝色折光N，使用原生VectorDrawable资源。API26自适应前景/背景，API33单色主题图标，保留一致的静态回退；不依赖位图库或启动时生成图片。源文件位于app/src/main/res；设计说明见ICON-DESIGN.md。

## 列表中的楼主图片

版块主题列表、搜索结果、本机收藏/历史、云端收藏和用户主题列表以及关注的新主题可显示首帖图片。回复记录仍按自身楼层定位，不把回复图片冒充楼主图片。

- 每条最多预览3张，点图进入现有原生图片查看器；点标题或其余行区域仍进入帖子。
- 只读取服务端明确确认的同一tid、第一页、具有明确首楼标记的首楼，楼层/index/声明的pid不得矛盾；缺失首楼、主题不符、权限不足、接口截断或请求失败时不显示预览，不回退到回复图片或网页抓图。
- 图片来自原生正文解析器认可的官方附件；引用、隐藏、加密和代码内容不进入列表预览；头像、表情和编辑推荐封面不作为首帖图片。
- 只有出现在屏幕内并停下约280ms的行才读取元数据；最多2并发、12排队。快速滚动、页面离开、后台和账号/域名切换会取消请求及迟到回调。
- 图片通过既有匿名图片组件读取，不向图片服务器发送账号Cookie。离屏释放视图持有的像素；没有图片的行不留空白占位。
- 元数据仅在内存缓存，按论坛域名与当前会话摘要隔离，最多96条；有图30分钟、无图5分钟、失败30秒。显式刷新会使当前会话缓存失效。已阅读的首楼可直接复用，避免返回列表时再次请求。
- 设置 → 帖子图片预览可以关闭。关闭后列表不主动读取首帖元数据，正常正文图片查看不受影响。

## 验证范围

Host回归覆盖首楼身份、可信图片提取、过滤、容量、TTL、并发、取消、会话隔离和刷新；Android fixture以真实生产组件及合成输入验证可见性、空白收起、点图、快速滚动和迟到回调；另在已登录专用模拟器读取公开宠物版块，验证缩略图、放大、返回、深色及窄/宽窗口。

首帖图预览需要额外的只读首帖请求，并受NGA网络、权限及附件可用性影响。仅预览最多3张，不代表首帖图片总数。模拟器窗口测试不等同实体折叠屏/旧系统实机认证；静态截图和抽帧不用于认证动画帧率。未用真实账号进行发帖、私信、点赞、举报、头像上传或云收藏改动。
