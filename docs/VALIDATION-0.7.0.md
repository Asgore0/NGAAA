## 写入与安全挑战

发布、上传、私信及收藏修改都有用户明确操作和确认入口。只有服务器明确确认后才能记录成功；未知结果不自动重试。私信未知送达后，本份编辑器保留正文并锁住发送，可关闭或先只读刷新核对，刷新不会自动判成功或重新启用发送。

无会话、权限、限流、安全挑战、网络、服务器错误和不可识别响应分别保留状态。当前没有原生验证码、短信或人机验证答题流程；投票/评分配置编辑和更多管理功能未实现。未知协议不得以官方网页替代原生功能或冒充成功。

## 尚未覆盖

- 新原生扫码由用户手机确认到服务端会话保存的完整正向链路，以及全新安装、账号切换和会话过期流程。
- 实际发布、上传、私信发送/回复、云端收藏写入；真实 quote / modify 准备与更多权限组合。
- API 26/31、CPU 模糊回退、厂商真机、低内存及长时间稳定性。
- 完整 TalkBack、大字体、更多键盘、横屏和低矮屏幕；更多图片动画与原图保存。
- 自然跨日 24 小时调度、系统省电/断网与厂商后台限制。
