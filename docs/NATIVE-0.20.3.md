# NGAAA 0.20.3 · 目录、个人页与设置排版

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

本版把「我的」入口按阅读收藏、互动、管理分组，保留全部 12 个入口及原动作。设置改为圆角分组，当前短状态靠右，宽度不足时完整换行，长说明不截断。原账号、签到、通知和域名功能保留。

板块网格把头像与名称放在上行，分类与收藏放在下行。名称可用空间增大；单列继续横向排列。收藏视觉字号收小，触摸范围至少 48dp。搜索框提示缩短为「搜索名称或 ID」，仍支持板块、合集与 ID。

搜索弹窗先填充历史、绑定回调，再显示和测量。两项搜索范围仅在完整文字都放得下时同行，否则上下排列。空历史减少重复标题与无意义清空按钮；读取失败保留清空恢复入口。搜索与账号生命周期守卫保留。

修复子版块网格从两列缩为一列时的重排顺序，避免旧列索引触发 Android GridLayout 异常。窄宽尺寸往返重排加入回归验证。

修复 Android 30+ 输入法关闭后浮窗仍使用旧可见区域的问题：系统明确报告键盘已隐藏时，以页面当前的折叠安全区域定位。搜索和跳页弹窗均使用此逻辑；旧系统继续使用原有可见区域计算。

原液态胶囊、固定玻璃背景及黑金 N 图标沿用。

验证以同批发布的审视报告和原始模拟器录屏为准。窄屏、大字、深色和宽屏由专用模拟器显示尺寸验证，不代表实体折叠铰链或全部设备的性能测试。独立测试使用无网络权限的单独包，模拟收藏变化不涉及真实账号。
