## 当前重建依据

- 主框架：底部 50 dp 导航及顶部分隔线，实际菜单文字“首页 / 社区 / 游戏库 / 我的”，当前按 16 sp 纯文字导航收敛。
- 首页：默认“关注 / 推荐 / 热帖 / 活动”，默认选中推荐；标签 18 sp / `#FEF9E6`，指示线 36 dp；深色顶栏、汉堡菜单、搜索和消息；推荐内容采用双列图文卡片。
- 社区：左栏 55 dp，8 个等高两行分类；右侧版块列表，顶部 40 dp / 16 sp 搜索框，提示“搜索版块、帖子、用户”；省略官方社区广告。
- 配色：直接使用实际包资源中 `#FFF9E4` 背景、`#FCF7E5` 表面、`#F4EFDD` 分隔、`#434343` 主文字和 `#D18F2E` / `#EFB973` 强调色；不再把早期截图估色当作当前规范。
- 抽屉和阅读：依据实际布局及截图核对；帖子底部常驻 48 dp 上下页、18 sp 页码、收藏和回复，已实际从 1/62 切至 2/62。我的页面、版块页头、部分卡片与间距仍有结构差异，不承诺全部页面逐像素一致。
- 游戏库：省略独立商业游戏推荐位，展示可真实读取的“传统游戏 / 手机游戏 / 影视”社区评分，明确其内容范围。

经典模式默认启用。可选玻璃由 Android RenderEffect、AGSL 和低版本模糊回退独立实现；AppKit 是 macOS 框架，不用于 Android。本轮已实际捕获官方清洁首页、社区和抽屉，并验证 API 35 浅深玻璃抽屉与系统关闭动画后的交互；过渡或不可用页面不计入通过范围。
