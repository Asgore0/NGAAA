# Android 0.7.0 验收清单

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

日期：2026-10-18。版本 `0.7.0 / code 7`，最低 API 26，编译与目标 API 35。最终 APK 大小、SHA-256 及发布校验见 release.json（历史附件未收入源码仓库）。本页只将本轮实际完成的检查标为通过，不沿用 0.6.0 全部设备结论。

## 本轮已确认

- [x] 阅读、扫码、编辑、资料、提醒、私信和收藏均有 Android 原生入口，无 WebView 或官方网页功能回退。
- [x] API 35 专用模拟器中已有授权会话可用，账号/私密响应不写入公开交付记录。
- [x] 推荐、版块主题、原生帖子与搜索真实读取通过。
- [x] 自己的资料、提醒和默认云端收藏真实读取通过。
- [x] 私信列表修复后真实读回 34 条；最后一页正确识别 `hasNext=false`，不凭条数猜造下一页。
- [x] 自定义收藏目录返回 `SERVER` 时明确显示失败；默认收藏可独立读取，不冒充空目录或目录成功。
- [x] new / reply 只读准备通过，取得权限与编辑元数据；未实际发布或上传。
- [x] 本机草稿 save/read/delete 实测通过。
- [x] 本轮服务器签到返回成功、今日已签到；这不是自然隔日任务验收。
- [x] 扫码离线 21 场景 / 98 断言、原生内容 7 场景 / 144 断言通过。
- [x] 发帖/附件协议 132 项、草稿 16 项离线检查通过。
- [x] 社区协议 114 项、未知送达策略 19 项离线断言通过；新社区组件严格编译通过，无真实发送。
- [x] 渲染器参考回归已记录 265 项通过；不将其当作原生正文完整设备验收。
- [x] 随源码的 Nayuki QR 编码器保留 MIT 许可头；测试 JAR、测试账号替身不打包到运行时 APK。
