# NGAAA 0.20.4 · 按钮与配色

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

采用共享 AppPalette 统一暖白、石墨、低饱和金色。主操作使用墨色底和浅文字，深色模式反转为暖灰底和深文字；金色用于小面积选中与标记。正文、次级文字、边框、波纹均区分角色。

通用弹窗的主次操作按可用宽度同排，窄屏或大字自动竖排；保留所有回调、按钮语义和至少 48dp 触区。跳页停留当前页时降低确认按钮的视觉强调，选择其他有效页码后才强调跳转。

目录、设置、阅读链接、登录、编辑、消息、投票和媒体控件同步配色。二维码、图片及作者明确指定的正文颜色保持原内容。系统控件随应用深浅主题设置强调色。默认原生弹窗显式继承浅色/深色主题，启用透明系统栏背景绘制，并加深浅色浮窗的中性遮罩，让系统状态栏与导航栏图标保持清晰可读。玻璃材质仅调整颜色常量，保持固定背景与既有运动算法。

具体模拟器验证、前后对照、交付文件摘要见同版本报告。颜色角色的对比度计算不等同于玻璃合成后的所有像素检测；不声称实体折叠屏或全 Android 版本均已验证。
