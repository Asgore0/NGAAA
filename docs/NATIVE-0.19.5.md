# Android 0.19.5 原生客户端维护更新

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

版本为 `0.19.5 / versionCode29`，包名 `cn.ngapure.app`，最低 API26，目标 API35。本轮集中处理长帖媒体占用、异步任务取消、窗口重建和会话切换。已有功能的累计范围见项目 README；本页只描述本轮改动及其验证边界。

## 长帖、图片与播放

- 长帖可以释放离屏图片的解码对象。释放前必须成功解码并把原始媒体写入应用私有缓存，以便返回时本地重新解码；保留原始逻辑宽高，避免重新加载时帖子高度跳动。缓存上限为 32MiB、128 项、7 天，单项不超过 20MiB。不会回收其他视图仍在使用的共享 Bitmap。系统清理缓存或媒体工作集超出缓存预算时仍可能重新下载；本项不承诺任意长帖的内存恒定。
- 同一动画的多个订阅仍共享下载，各自拥有动画实例。独立动画解码增加主线程交付背压，避免主线程繁忙时积压多份已解码动画；关闭或最后订阅取消时能够退出等待。
- 图片布局使用原始逻辑尺寸，而不是采样后的小位图尺寸，改善长图和大横图被压得过窄的问题。解码像素预算、小图不放大及既有高度上限保留。JPEG 在 BitmapFactory 路径按 EXIF 的旋转、镜像方向显示；ImageDecoder 路径沿用系统方向处理。导出仍保留原始编码字节。
- 帖子上方的图片晚到并撑开内容时，按当前屏幕可读文字的位置补偿滚动，覆盖不同帖子之间以及文字刚进入阅读区边缘的情况。用户主动触摸、滚动或页面离开后取消这次补偿，避免图片返回时把阅读位置拉回；触摸记录使用弱引用，不保留旧滚动页面。
- 原生图片查看器保存相对缩放与中心位置，支持图片异步返回前恢复，以及旋转、窗口尺寸变化后的视口恢复；保存状态仅包含图片地址和少量数值，不持有旧 Activity 或 Bitmap。
- 原图准备接入页面只读任务取消。离开图片 A 后，其下载可主动断开；A 的迟到回调不能改变图片 B 的下载中标志或按钮。离开 B 同样清理其准备状态。
- 用户在系统选择器确认后的原图保存由进程内独立队列执行，使用应用上下文，最多一个工作线程、两个等待任务。窗口重建不会中断该队列；队列满时直接提示繁忙，不在主线程写文件，也不自动重试失败写入。此保障以应用进程仍存活为前提，不承诺进程被系统终止后继续保存。
- 连续短暂失去音频焦点时保留原有恢复播放意图；用户明确暂停、永久失焦或进入后台停止后仍不会自行重播。格式与编解码支持继续由 Android 设备决定。

## 窗口、输入与身份

- 子版块入口缩小头像与间距，默认展示两个入口，可展开全部。布局按可用宽度及字体缩放选择单列或双列，保留独立收藏星标与原有打开路径。展开状态随当前版块和返回栈保存，进入子版块再返回或窗口重建后继续保留；恢复仅接受匹配的合法版块路径和布尔值，不增加全局偏好设置。
- 返回前台、重新获得焦点，以及可见窗口收到账号或线路变化时，核对完整 host/account/Cookie 会话。真正变化后刷新旧内容、取消旧页面读取并清理旧阅读位置；同一批首选项变更合并处理。主题、字号、签到记录变化不会因此重建页面。
- 系统选头像进入本地裁剪后，窗口重建可恢复同一会话的内容 URI、裁剪中心与缩放。保存的是有界文本和数值，重新读取本地图片生成预览；不会自动上传。取消会立即移除可恢复状态并拒绝迟到解码，旧私有预览位图随页面释放。退出动画期间迟到的确认点击也在裁切与任务入队前被拒绝，只有当前仍显示、未关闭且确认可用的所属弹窗能够提交；已进入提交阶段的预览不会恢复成可再次确认的裁剪页。
- 搜索与跳页弹窗保存未提交文本、光标及页面/会话身份。恢复只还原输入，不自动搜索、不自动翻页。帖子跳页等待新响应提供总页数，旧总页数不作为新请求权限依据；取消、提交、换页或换会话的输入不能复活。搜索长度、控制字符与过期窗口提交也有独立检查，错误保留在当前输入框供修改。
- 原生玻璃弹窗的正向、中间与取消按钮统一检查窗口仍显示、按钮可用、窗口未开始关闭及宿主 Activity 仍有效。调用方替换点击监听器后仍经过同一检查，关闭动画期间、按钮禁用或旧宿主失效后的迟到点击不会再执行操作。

## 登录、编辑器与后台任务

- 关闭二维码或账号/验证码登录页时，同步撤销当前尝试并清理敏感输入，连接清理由有界后台任务执行；清理队列饱和时不会回退到主线程断开连接。已取消的响应停止继续读取，迟到授权不能覆盖登录状态。窗口重建所需的二维码授权恢复仍保留原尝试的检查点，区别于明确取消。
- 编辑器获取发帖权限属于可取消的只读任务，离页后可释放阻塞读取。已经开始的正文提交或附件网络写入继续完成其结果收尾；响应不确定时保留待核对草稿，不自动重发，也不让关闭页面后的回调导航到新帖子。
- 未读检查按每次 Job 的所有者和取消令牌管理。停止、替换或销毁旧任务时断开其只读连接，旧完成回调不能结束新任务。有效检查遇到其他读取占用时向系统请求稍后重试，不把“尚未检查”记成成功，也不释放其他任务的占用标志。
- 前台自动补签合并同一未决会话的重复触发，避免旋转、折叠等重建形成连续失败重试队列。旧 A 收尾期间若请求了 B/C，只保留最新一个完整会话的后续机会；返回同一 A 不重复补排。任务的预期会话贯穿到 NgaApi，不能因执行前再次读取账号而替未请求的新账号签到。已经开始的原请求不被会话切换打断；其结果仍受账号归属检查。同一 UID 更新令牌时，原请求的明确成功按原有账号语义记入当天。

## 固定材质与平台边界

与已发布 0.19.4 源码逐字比较，`GlassPanel.java`、`LiquidSelection.java`、`LiquidMotion.java`、`Motion.java` 均未修改。固定浅色/深色底材、胶囊跟手形变、融合、高光和动画参数保持原版本；滚动或异步加载不重新采样页面背景。弹窗本轮增加的是输入恢复与关闭状态检查。

Android 侧继续使用原生 View、Canvas、系统图片解码及 MediaPlayer。外部活动与第三方网页由明确链接交给浏览器；官方腾讯安全验证使用独立 WebView。Spine 特殊内容、第三方视频页面与设备编解码限制仍按 README 所列边界处理。

签到和未读后台任务受 Android 调度、省电和通知权限限制，不能保证准点或实时。折叠屏检查包含窗口尺寸变化与合成铰链数据，不能代替每种厂商折叠设备验证。API26/27 兼容路径有离线编译与逻辑覆盖；本轮 Android 组件执行证据来自 API35 环境，不宣称已在 API26/27 真机重测。

## 验证范围

本轮使用离线协议/持久化测试，以及独立应用 UID、无 INTERNET 权限的 Android 辅助程序，执行真实生产 Activity、View、解码器、播放器、JobService 和本地 ContentProvider。辅助程序直接绑定指定候选包的生产类并记录哈希，合成响应、图片、音频、账号与输入均在独立数据空间中。文件保存通过本地管道比较完整字节，不访问用户文件或远程文件提供方。

登录、发帖、上传、签到等写路径使用合成传输或本地提供方验证；本轮没有为验收实际发送短信、发布帖子、改头像、点赞、投票、举报、发私信或修改真实云收藏。合成登录和签到不能替代对真实 NGA 账号、验证码服务、线上权限及服务器结果的完整复测。已有功能也不等于本轮所有功能都做过端到端实测。

可重复执行的源码包括 `tests/checkin_service/`、`tests/api/checkin/`、`tests/credentialauth/`、`tests/posting/`、`tests/notifications/` 及各 `*_device` 辅助目录。本轮独立 Android 辅助构建显式绑定候选生产类与校验和；新增的编辑器、登录、未读和原图保存辅助脚本要求外部签名目录，不默认引用可变构建缓存，不自动连接设备。辅助程序、测试依赖和签名密钥不进入客户端 APK。

最终包对应的设备记录、源码重建结果与哈希，以随安装包提供的验证报告为准。
