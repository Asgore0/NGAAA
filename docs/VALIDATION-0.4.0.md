## 图形能力与未覆盖边界

Android API 31 起使用 [RenderEffect](https://developer.android.com/reference/android/graphics/RenderEffect) 对独立背景层模糊；API 33 起使用 [RuntimeShader / AGSL](https://developer.android.com/reference/android/graphics/RuntimeShader) 处理局部光学效果。更低版本采用 CPU 模糊或实色回退，文字与按钮保持在材质层上方。

当前只在 API 35 实测。实色开关通过说明当前设备能切换到实色，不代表低 API 或 CPU 回退已经通过；API 31–32、低内存设备和厂商真机仍未覆盖。没有等待完整 24 小时验证自然后台签到；此次“今天已签到”也不等于自然隔日调度成功。

应用和系统关闭动画的最终 APK 路径均已实测，不再列为未测。其余登录渠道、会话过期、更多屏幕尺寸、长时间运行、实际发布和附件上传仍按独立场景记录。
