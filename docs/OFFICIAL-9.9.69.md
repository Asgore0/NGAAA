## Android 玻璃材质与动画

[AppKit](https://developer.apple.com/documentation/appkit) 是 Apple 的 macOS 图形界面框架，不能链接进 Android APK。本项目使用 Android 原生渲染接口重新实现近似的玻璃材质。

| 环境 | 实现 |
| --- | --- |
| Android 13+，硬件加速、正常内存 | 截取本应用指定背景 View 的缩小快照，用 [RenderEffect](https://developer.android.com/reference/android/graphics/RenderEffect) 模糊，再由 [RuntimeShader / AGSL](https://developer.android.com/reference/android/graphics/RuntimeShader) 处理边缘采样偏移，叠加着色与高光 |
| Android 12 / 12L | 背景快照和 RenderEffect 模糊，使用 Canvas 边缘高光 |
| Android 8–11、软件绘制或低内存环境 | 工作线程执行三轮可分离 box blur，再叠加着色与高光 |
| 分配、绘制或着色器失败 | 回退至可读的不透明表面；着色器异常优先回退原生模糊 |

文字和按钮放在材质层上方，保持清晰。背景快照只来自本应用 View；无需录屏权限，也不保存到磁盘。采用有限分辨率、事件触发更新和节流，不逐帧截取背景。因此玻璃底图不会持续追踪滚动变化；这是 Android 近似材质，不是 Apple 私有材质的原样移植。

动画使用 Android 属性动画：按压约缩至 97.5%、松开采用阻尼回弹；页面进入采用轻微位移与淡入；抽屉采用滑动与阻尼。系统关闭动画或动画缩放为零时，直接进入终态并执行完成回调。API 35 上已验证 `animator_duration_scale=0` 时抽屉关闭与社区切换到达终态，随后恢复原先未设置的系统值。低版本 CPU 渲染回退未实测。

原生客户端没有集成广告 SDK，并省略开屏广告、悬浮广告容器及部分商业分发位。官方评分中的商业“游戏推荐”使用独立交易相关 API，匿名请求未成功，本轮不重建其签名或将其他分类冒充该内容。

4. 开启自动签到后，打开应用触发补签，服务器实际返回签到成功。
