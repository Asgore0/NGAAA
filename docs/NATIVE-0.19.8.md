# Android 0.19.8 版块发现与排列

版本 `0.19.8 / versionCode32`，包名 `cn.ngapure.app`，最低 API26，目标 API35。基于0.19.7的原生目录改进。

## 五步使用流程

1. **收藏和最近**：顶部提供收藏、最近、全部三个入口。版块星标仍沿用原有NGA云端自动同步；最近访问是当前账号和域名在本机的成功打开记录。
2. **排列**：默认紧凑网格，按实际内容宽度和系统字号使用1—3列。可在排列按钮切换清晰列表，选择保存在本机。头像保留，收藏按钮至少48dp，名称最多两行；宽度不够或字号增大时减少列数。
3. **分类直达**：分类按钮打开原生选择弹窗，列出目录分类及入口数量。无需反复横滑，也不添加会遮挡内容的侧栏。
4. **全目录搜索**：输入时按名称、别名、编号及目录元数据查找全部目的地。精确编号和名称、名称前缀优先，同一相关度内收藏优先，空查询保持目录原序。清空搜索回到先前的目录模式和分类；键盘完成只结束本地筛选，不意外跳到帖子搜索。
5. **打开与返回**：普通版块与主题合集使用各自的规范编号，合集保留父版关系。网格改变列数、进出页面及窗口重建以稳定编号和有符号顶部偏移恢复位置；用户触摸、改分类或改查询时取消过期恢复任务。

## 目录数据

内置官方目录快照的674条记录规范化为658个不同目的地：372个普通版块和286个主题合集；16条重复路由合并别名与分类。合集中出现的fid仅作为父版信息，不再冒充合集自身编号。非法声明的合集编号不会降级打开父版。相同目的地可能属于多个分类，因此各分类数量之和不必等于总数量。

目录仍是随包提供的官方数据快照。未收录的版块、合集以及已收藏或最近打开的有效目的地可通过编号和官方链接进入。没有伪造实时热度或访问排行。

## 最近访问与保存

- 只记录成功加载的版块或合集；失败或仍在加载的请求不会记为成功访问。
- 使用账号身份和论坛域名的64字符摘要隔离，最多保留6个范围、每个范围30条。编号去重，新成功访问放在最前。
- 保存名称、父版关系、规范图标和时间，不保存正文、登录凭据或Cookie，也不上传最近访问。
- 关闭浏览历史后暂停新增访问记录。清空浏览历史时一并清除当前范围的最近访问，也可在目录菜单单独清空最近访问。
- 后台写入有界，清除操作会使旧队列任务失效。存储读取损坏或提交失败保留先前状态，不以空记录覆盖其他账号的数据。突然强杀可能丢失最后尚未落盘的一次访问。
- 旧版本仅有数字行号、无法绑定账号的目录位置会安全回到顶部；原有六字段首页状态保持兼容。
