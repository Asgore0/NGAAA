## 完全无应用缓存时的启动路径

直达或恢复板块页时，主线程不再先解析完整板块目录。它保留必要的会话校验与少量内置名称，先发起板块请求，列表首次绘制后再在后台读取完整目录。网络失败或在响应前返回其他页面也会启动目录读取；返回目录时有短暂的原生加载状态，完成后显示全部条目，保留分类、搜索与导航状态。首页收藏板块在目录就绪时更新名称。普通首页启动仍载入目录，但清洗成本降低。

目录中不含 HTML 语法、空白、控制或其他需要归一化字符的文本走严格字面路径；其余文本仍使用原 Android Html 解析、控制字符清理和长度截断。网络正文解析、板块顺序、别名、图标、合集和搜索元数据不变。没有以进程缓存、预取或增加后台请求来冒充首次加载改进。

签到和通知新增仅用于启动阶段的异步入口：独立串行队列合并重复触发，本地调度与会话读取不阻塞 UI，也不排在慢 HTTP 后面。现有登录/退出、关闭提醒等显式操作保持同步语义；后台执行时重新确认当前会话并沿用请求及回写的账号校验。自动签到、通知选项、云收藏和云屏蔽规则继续生效。

## 验证与诊断

新增启动阶段诊断仅记录相对 onCreate 的单调时钟时间、目录解析时长和任务计数，不记录账号、Cookie、URL或正文。networkStartedNs 表示开始调用板块读取 API，并非单独 DNS 或 TLS 时间；既有响应头等待包含连接建立/握手。firstDrawNs 是 CPU 绘制回调，不代表 GPU 呈现。

本轮对比须使用 0.20.10 与最终 0.20.11：真实客户端每轮结束进程并只清空应用 cache 临时文件，保留登录、收藏、草稿和阅读记录；独立测试包每次全新安装、单次冷 Activity 及首请求，旧新版交替，分别使用受控响应和原生匿名 HTTPS。系统 DNS/页缓存与 ART 配置不人为清空。采样 trace 只用于单独定位，不混入性能统计。以随版本报告中的最终实测为准，不将短时缓存命中计作本次冷启动提升。
