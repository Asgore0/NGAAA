# 首次打开板块的性能记录

场景：保留真实登录状态，每次清空应用缓存并重新启动进程。每个候选与 0.20.12 交替比较，三轮，每轮七对；每次安装后先完成一次不计时预运行。

主指标是 `MainActivity.onCreate` 到帖子内容第一次 `OnDraw`，不是系统完整启动、所有图片加载或 GPU 呈现完成。

## 原定门槛

每轮中位数至少快 5%；至少 15/21 对更快；配对差 95% bootstrap 区间上界小于 0；P90 不恶化超过 5%；功能检查全部通过。每个实际代码候选只进入一套完整三轮测试，不删除慢样本或挑选轮次。

## 本地复算

```sh
python3 scripts/verify-performance.py
```

脚本确认所有数值、顺序和统计结果可复算。退出成功表示证据内部一致，不表示每个候选都更快；未通过的性能结果会明确显示。

## 范围

系统、DNS、ART 与服务端缓存没有重置。Android 15 从强制停止状态恢复可能触发 BOOT_COMPLETED。这些结果不能代表所有设备或所有启动方式。响应头耗时包含建连和等待等多种因素，不能单独归因于服务器或并行竞争。

公开数据仅保留原顺序的数值、功能检查布尔结果和产物哈希；账号、Cookie、二维码、设备转储和本机路径均未包含。功能检查的完整原始诊断保留在开发环境，公开统计数据不替代这些检查。
