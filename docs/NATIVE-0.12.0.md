# Android 0.12.0

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

本版集中调整帖子排版、底部液态玻璃胶囊与折叠/多窗口阅读体验，保留原生 Android 界面及0.11.0的认证、接口、存储和签到实现。

## 界面与交互

- 楼层使用圆角卡片，作者、时间、楼层和正文分层。作者入口保持48 dp点击区域；底部收敛为一行48 dp操作，赞数在左，引用回复和更多在右，复制与本人编辑移入更多菜单。正文默认16 sp，跟随既有字号设置；赞数继续区分明确点赞、净赞与未知。
- 正文调整行距与基线。引用使用浅色圆角面板与竖线，三级以后保留原文但不继续压缩阅读宽度；代码保留空格、制表符和换行，长行横向滚动。链接保留下划线，居中对齐可由原生文本识别；拆分引用后，外层粗体、链接和对齐仍延续到引用及其后正文。图片圆角更新，按视口加载、离屏动图停止和图片变高后的文字锚点逻辑保留。
- 胶囊在快速反向拖动、重新抓取和连续点按时延续当前几何状态与速度；松手以手指意图提交选择。多指替换与拖动中尺寸变化保留驱动状态。光学层继续使用独立背景采样，文字与图标位于上方；本次不以主机轨迹结果宣称真机固定帧率。
- 正文列最大680 dp，通用内容列最大720 dp，首页胶囊最大480 dp并居中。底栏按字体比例使用64或69 dp高度，相应更新内容底部留白与系统栏边距。展开窗口提供受控行宽，窄窗口按可用空间缩放。
- 阅读位置增加“楼层＋楼层内比例”锚点，只在阅读列宽度改变时重排定位；同宽度恢复沿用原滚动位置。保存状态校验目标路由并限制数据量，返回栈最多32项，防止错误帖子或旧状态套用当前位置。

## 验证范围

0.12.0 / versionCode13安装包已覆盖安装，16组离线回归及正文、胶囊输入、媒体、阅读恢复、分页、账号状态、实际窗口和界面检查通过，设备记录（历史附件未收入源码仓库）的30项检查标志均为真。正文探针验证原生对齐、链接下划线、代码横滑与折叠；32层引用在28 sp下仍保留可读宽度。实际360 dp、840 dp及360 dp配1.3倍系统字体均未发现受检内容裁切；展开时正文680 dp、胶囊480 dp。窗口展开与收窄后均保留第21楼，楼层内比例差各25/10000。设备快速手势7项通过，交接几何跳变量为0，静止后停止帧回调；这不是设备固定帧率承诺。详见 [验证总览](VALIDATION.md) 与 [设备清单](DEVICE-TEST-CHECKLIST.md)。

本版模拟器录屏（历史附件未收入源码仓库）约51秒，展示首页卡片进入帖子、引用、第2页头像/净赞、360→840→360窗口变化保留第21楼及返回首页。原始screenrecord文件未剪辑、变速或插帧；展开段黑边由Android录屏生成。8个时间线样本及4个补充动作样本已解码并目视审核，截图归档于 `screenshots-0.12.0/`。源码与最终验证文件分别为 `NgaPure-Android-0.12.0-source.zip` 和 `NgaPure-0.12.0-verification.json`，与APK、录屏一同交付。

本轮保留账号与签到状态，没有新扫码授权、真实密码/SMS正向登录或真实内容写入。历史自动签到成功仍归属原版本；本轮不能据保留的完成记录声称重新签到。

适配基于应用窗口和系统栏边距。当前没有读取物理铰链间隙或分隔区域；模拟器尺寸变化不等于物理铰链认证。尚未覆盖所有真机、Android26运行、Doze或厂商后台限制。
