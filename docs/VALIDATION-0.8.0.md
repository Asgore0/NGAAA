## 设备与联网

最终 APK 完成 24 项原生 UI 检查：单层导航、连续折返/重新抓取/跨项点击、公开帖子及图片查看、系统原图保存、中文表情与折叠预览、发帖草稿旋转与离页恢复、私信草稿重启恢复与明确清除、收藏列表返回恢复位置、提醒和保留登录。所查页面均无 WebView。图片导出真实写出 400940 字节 WebP，文件头与后缀一致，测试文件随后清除。图片动态加载后的精确内容锚点仍有限制。

16 项联网及本机检查中，15 项通过，主题搜索在最终复测返回服务不可用，单列为未通过。通过项包括推荐 20、版块主题 86、正文/作者字段、自身资料、私信列表 34、既有已读会话正文 20、提醒 1、收藏目录 1、默认收藏 30、new/reply/quote 只读准备、本机草稿读写删除、已有会话及签到。签到服务器明确返回 `success=true, already=true`。搜索先前候选包曾返回 32 条，但不计入最终包的通过数。

扫码页初始化、90 秒自动暂停、手动“确认登录”、刷新和原账号保留已实测通过。现有授权会话的原生交换与确认组件得到 SUCCESS：真实收到会话 Cookie pair、核对授权账号并验证有效性。此前用户扫码的临时双钥随模拟器退出丢失，**新二维码授权至保存的完整正向流程仍未确认**；已有会话组件测试不替代扫码验收。
