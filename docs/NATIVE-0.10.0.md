# Android 0.10.0

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

本版新增账号密码、手机验证码入口，调整收藏和版块布局，并显示帖子推荐数据。阅读、搜索、编辑、资料和收藏仍由原生 Android 界面呈现；仅短信人机验证单独使用腾讯官方安全控件。

## 本版变化

- 确认登录按钮保持固定样式，后台授权轮询不再每三秒将按钮变暗。重复点击仍受请求状态约束。
- 登录页提供扫码、账号密码、手机验证码三种方式。密码使用 NGA 图形验证码；短信需要用户点发送并完成官方腾讯验证。密码、验证码不会写入页面恢复状态。
- 首页顶部固定“收藏版块”入口。版块页提供收藏/全部两页，分类改为横向选择，内容单列并在宽窗口居中。菜单根据当前可见窗口限制宽高。
- 云端帖子收藏采用横向目录、独立分页和更紧凑的帖子行；回复收藏携带目标楼层，返回后保留阅读位置。
- 帖子进入和返回采用可中断的位移、透明度过渡。退出、尺寸变化和新导航会释放旧页面快照及触摸遮罩。
- 支持真实人物头像、已核实的官方版块图标。没有头像或图片加载失败时保留有辨识度的文字占位，不编造人物照片。
- 每个主题和楼层保留赞数位置。官方显式“推荐值,支持,反对”三元字段的支持数显示为点赞；楼层的标量推荐值按官方公开界面的口径标为“净赞”。主题列表的标量推荐级别不当作评分或点赞数。
- 已打开的帖子优先使用正文数据中的点赞或净赞。两者均缺少时，按整页尝试读取一次官方 HTML 数据补全；只解析数据，不运行脚本。不会为列表中每个主题或每个楼层增加请求。补全被服务器拒绝或数据仍缺失时显示“—”，不会猜为零。

## 实测范围

本版设备实证、输入源码 SHA 和已安装 APK 校验见 `device-checks-0.10.0.json`。窄屏与展开尺寸通过同一 API35 模拟器临时改变显示尺寸检查，不能代表真实折叠铰链、厂商分屏和低版本系统已验收。

确认按钮在授权轮询期间连续采样13秒，39张内存截图的按钮区域像素哈希一致；二维码像素没有保存。手点未授权二维码只验证等待状态，不冒称本版又完成了一次手机授权。原账号由前版真实扫码取得，本版覆盖升级后复验。

账号密码页已显示真实 NGA 图形验证码；匿名腾讯控件已实际加载，SDK、控件节点和验证 iframe 均存在，取消后销毁。没有提交真实密码、发送短信或完成密码/SMS正向登录，相关协议成功路径由合成测试覆盖。前版扫码成功与自动签到记录保留原版本归属。

自动签到沿用账号隔离及当天去重机制。本轮跨过自然日后，10月19日00:06打开应用取得服务器“签到成功”，没有修改系统日期或当天缓存。系统后台调度不保证立即执行；自然等待24小时、无人打开时的跨日调度、Doze和厂商后台限制尚未实测。

## 隐私与交付

客户端不含广告 SDK、开发者统计或中转服务器。验证码控件仅加载所需官方安全资源；手机号、密码、论坛 Cookie 和二维码授权信息不传入控件。账号凭据使用 Android Keystore 加密保存在设备私有目录。

截图及录屏只展示公开页面。二维码、账号信息、私人收藏、凭据、验证码票据、安装签名私钥和设备私有目录不进入交付包。源码包保留构建方法、许可、合成测试和各版本验证范围。
