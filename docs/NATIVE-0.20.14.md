# NGAAA 0.20.14

2026-10-25，versionCode 48。基于 0.20.13，修复帖子楼层的点赞/点踩操作。

## 修复

- 官方 `raw=3` 响应可能是包含单个数据赋值脚本的 HTML 文档。旧解析器只接受 JSON 或裸赋值，因而误报“服务器没有返回可识别的确认结果”。新解析器接受精确的官方文档外壳，只解析数据，不执行 JavaScript；额外脚本仍拒绝。
- 合法的推荐值变化和状态位足以确认结果，提示文字可空。零状态位表示保留已有选中状态，不能误称已取消。
- 结果不明确时仍阻止自动重发。用户核对后可通过“核对后重新操作”解除当前账号、当前楼层的本地保护，再单独确认新的操作。解除本地保护不会发送网络请求。
- 服务端确认后原地更新楼层按钮，不重建整个阅读页、不重置滚动位置。独立点赞/点踩总数另行读取，不能用净值变化猜测；旧补读不能覆盖新操作，只有净值的响应不再把已有总数清成横线。
- 本次确认过的选中状态按账号会话及帖子楼层隔离，支持页面刷新和 Activity 重建；这不是全设备点赞历史同步。

## 验证方法

官方接口封套使用无 Cookie、无操作名、无帖子编号的匿名请求核对。相同封套在原 0.20.13 生产 JAR 中解析失败、修复版通过。成功与撤销响应使用合成数据回归，不对真实帖子执行点赞或点踩。

Android 测试使用独立应用 UID、无 INTERNET 权限以及未经改写的生产 JAR；测试账号和响应均为本机合成。新 APK 使用原签名，可覆盖安装并保留设备已有登录数据。公开源码和 APK 不含个人登录状态或测试模拟器数据。

本轮不重新宣称启动性能提速，也不把合成回归等同于真实 NGA 账号的投票权限验证。
