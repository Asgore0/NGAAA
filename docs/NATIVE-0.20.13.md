# NGAAA 0.20.13

2026-10-25 本地验证记录，versionCode 47，对应冻结候选 c8。该源码已通过事先固定的三轮性能门槛；这项结论只适用于下述环境和方法，不表示 GitHub 已发布或远端 CI 已成功。此前已发布安装版为 0.20.12。

## 本次变化

- 板块真实读取提前，与页面控件构建重叠；同一次请求交付结果，保留取消、页面代次、账号隔离和缓存写入校验。
- 主题列表采用原生 ListView 按可见区域创建和复用行，保留图片预览、返回与旋转后的阅读位置恢复。
- 缩短会话和收藏协调中的锁持有范围；自动收藏前台准备移入后台，保留显式操作及过期账号结果保护。关闭的通知、签到及当日已完成签到跳过不必要的会话读取。
- 同一批主题时间共用一个懒初始化格式器，避免逐条重复构造；各次解析和线程仍完全隔离。

## 本地验证

与 0.20.12 在同一 Android 模拟器、既有登录态下交替比较，共 3 轮、每轮 7 对、42 次计分启动；没有重试或剔除样本。每次安装先完成不计分启动与自动任务检查，再 force-stop、清空应用缓存并以新进程计分。主指标从实际 `onCreate` 入口到完整板块内容首次绘制，单位如下。

| 轮次 | 0.20.12 中位数 | 0.20.13 中位数 | 中位数缩短 |
| --- | ---: | ---: | ---: |
| 1 | 191.260 ms | 175.229 ms | 8.38% |
| 2 | 159.928 ms | 132.706 ms | 17.02% |
| 3 | 149.935 ms | 130.419 ms | 13.02% |

预设门槛全部通过：每轮中位数至少缩短 5%，17/21 对更快（要求至少 15 对）；按轮分层重采样的配对差中位数 95% 区间为 [-40.145, -16.776] ms，区间上界小于 0；合并 P90 从 230.435 ms 降至 181.744 ms，满足不劣化超过 5% 的门槛。三轮完整性、登录态及自动任务检查也通过。较早候选的失败结果保留，不与 c8 的样本混算。

离线证据共 18 套、10829 项：本候选实际重跑 9 套、10069 项；另 9 套、760 项在完整依赖与原日志哈希核验后复用。API 中 5145 项检查来自日期边界及 144 个并行混合列表批次，不能解释为新增了同等数量的产品功能。公开源码在 macOS / JDK 17 / SDK 35 独立构建，508 个 class 与冻结生产 JAR 逐项字节一致；签名外置，临时开发签名产物不作为正式安装包发布。

## 结论边界

这些结果支持本次登录态保留、应用缓存为空的指定冷启动场景通过本地稳定性门槛，不是所有设备、板块或网络下的固定提速保证。系统、DNS、ART 和服务端缓存未重置，互联网时延仍会波动；force-stop 后恢复也不等同于普通系统回收进程，`onCreate` 之前的工作不包含在主指标内。不能把整体改善全部归因于单个修改，或声称 NGA 服务端变快。

本轮保留正常的签到、收藏和通知策略，没有把全部后台任务推迟到首屏后，也没有增加假预热请求。登录态和自动任务检查不等于重新验证扫码、短信、真实补签、发帖、私信等每一项线上操作；离线夹具不替代这些实测。Linux 构建、GitHub CI 和发布状态需另以实际结果确认，录屏只作交互演示。
