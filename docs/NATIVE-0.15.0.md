## 云端版块收藏

收藏版块页提供明确的“从云端同步收藏版块”入口。官方 forum_favor2 的只读同步接口返回版块与合集，与主题/回复收藏的 topic_favor_v2 接口分开。仅导入本机，保留本地收藏；不自动上传、取消或删除云端内容。

账号/域名范围、页面代次、请求身份与本地收藏修订号共同约束导入。请求期间任何本地星标编辑使本次导入作废，避免取消项被晚到结果重新添加；失败或空云端列表不会清空本地。目录没有的收藏也可显示，名称和图标元数据保存在本机。

## 子版块与合集

解析同一次官方响应的 __F.sub_forums，区分普通子版块、主题合集及镜像标记。元组里的镜像主题 ID 不再被错当版块编号。普通入口使用 fid/ff，合集使用独立 stid；返回、分页、页码跳转与恢复保留对应身份。

原生入口默认 6 项，支持展开/收起；窄屏一列、展开窗口两列。使用对应版块/合集自己的官方头像地址，缺图时保留原生文字头像。

## 手机号身份补填

官方发码返回用户名/用户ID错误时，未指定身份的请求进入 ACCOUNT_REQUIRED。兼容 msg、message 及 error[0] 数组/数字键对象；同样文字在密码登录和验证码提交时不会被误当作发码补充流程。

短信页直接展示用户名/UID输入；补填不自动发码。手机号或身份修改清除旧短信码，输入修订号使 A→B→A 也不能复用旧验证回调。请求和安全验证时锁定输入；过期结果不能提交会话。失败发码与成功发码均显示客户端本地节流剩余时间，避免再次白做验证。官方 smslogin 仍用手机号和 RSA 加密验证码，没有自行扩展账号字段。
