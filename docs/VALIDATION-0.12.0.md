## 设备记录

API35模拟器的 `TypographyProbe` 已通过全部15个布尔检查。它验证原生链接下划线、居中对齐、外层粗体延续、代码空白与横滑、嵌套引用、延迟折叠及展开/收起。合成布局分别测量280/620 dp宽度；32层引用在28 sp字号和280 dp宽度下，正文可读宽度仍不少于180 dp。使用关闭的图片加载器，无合成图片网络请求，结束后恢复原页面。结果与限制见 [设备清单](DEVICE-TEST-CHECKLIST.md)。

实际360 dp、840 dp与360 dp配1.3倍系统字体三种窗口检查均通过：正文与控件未被裁切，长代码在自身横向视口内滚动，48 dp操作区域不重叠；840 dp窗口的正文列为680 dp、居中胶囊为480 dp。真实窗口尺寸变化及Activity重建后，展开与收窄均保留第21楼，楼层内比例差各25/10000；结束后恢复原窗口和字体。

胶囊设备输入7项全部通过：反向、取消、多指替换、纵向让行、快速往返、重新抓取和连续点按。实际注入输入及原生轨迹记录中，DOWN/目标交接的最大几何分量差均为0；静止后停止帧回调。连续16次点按合并到最终意图，最终回到同一首页时没有额外页面重建。这个结果不代表设备固定60/120 FPS。

MediaProbe复验通过：请求上限、取消、缓存迟到回调与可见性生命周期保持；合成图片从80增高到500像素后，文字锚点差0像素。普通帖子与PID帖子经重建均恢复自选1260像素位置，返回首页和trimMemory后几何保持。公开回复首次及重复定位均匹配第2页/目标楼层，19条回复有可核实净赞，10个真实头像均解码；未获得明确正赞字段，不据净值推断点赞。分页探针读出同一公开主题20条正文与67页分页。

受检窄屏/展开版块列表、单层底栏、菜单可达、明暗主题恢复及后台返回玻璃重建均通过；保留日志缓冲中未发现应用崩溃。真实iflogin返回HTTP200、协议码0、verified=true；自动签到开启、当天确认及Job计划保留。成功记录仍来自0.10.0于2026-10-19 00:06:42的打开应用补签，本轮没有清除记录或重新签到。
