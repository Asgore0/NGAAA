# 0.10.0 验证范围

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

当前版本为0.10.0 / versionCode11。对应APK、源码、录屏和验证JSON由同一发布流程校验哈希，历史制品保留原版本归属。

本版修复确认登录按钮轮询闪烁，新增原生账号密码与短信表单、收藏与分类布局、头像、帖子进退动画和按页点赞补全。字段证据及限制见 [本版说明](NATIVE-0.10.0.md)。

离线授权、恢复、账号隔离、API解析、头像及点赞元数据、正文和社区测试均绑定输入SHA。指定Android lint检查无错误或警告；原API测试harness有4项既有Unsafe编译警告。Main旧Android API的deprecated编译提示单独保留，不误报为全工程零警告。

设备检查使用专用API35模拟器。真实密码/SMS正向、短信发送、新扫码授权、自然跨日、Doze、低版本和厂商真机不在本版已验证范围。测试没有发布、上传、发送私信或变更云端收藏。

最终计数与设备结果以 本版校验报告（历史附件未收入源码仓库） 为准。历史 [0.9.1验证](VALIDATION-0.9.1.md) 与 [0.9验证](VALIDATION-0.9.0.md) 不计入本版设备检查数。
