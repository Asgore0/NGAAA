## 设备结果

专用 API35 模拟器已运行 MediaProbe、OptimizationProbe、ReaderProbe、已保留账号验收和公开界面检查。图片测试的真实队列和回调在设备上执行，但测试媒体为本机合成内容，工作线程屏障或关闭的加载器保证不请求合成图片地址。文字锚点在图片由80变为500像素高后差异为0像素。GIF 检查使用实现 Animatable 的合成 Drawable，证明可见性与停止逻辑；不能将其替代所有真实动图解码的兼容性验收。

普通帖子与指定 PID 帖子经 Activity 重建后均恢复到用户自选1260像素位置；快速底栏切换尚待提交时保存状态，恢复的标签和偏移也匹配实际呈现页面。公开回复定位复测读取到20条净赞、8个头像，8个真实头像均解码；没有明确正赞字段，故显示“净赞”，没有把净值解释为正赞数。

本轮对保留会话的 `iflogin` 请求返回 HTTP200、协议码0、verified=true。设备仍保留当天自动签到确认、任务计划和启用设置；成功记录来自0.10.0在2026-10-19 00:06:42的“打开应用补签”，本轮没有清除缓存或重新签到，不能写成0.11.0完成了一次新签到。

窄屏与展开尺寸、单层底栏、菜单可达性、明暗主题还原、后台返回玻璃重建及保留日志中未见应用崩溃的检查均通过。尺寸通过同一模拟器临时更改显示参数完成，测试后恢复，不是物理折叠铰链认证。检查细节见 [设备清单](DEVICE-TEST-CHECKLIST.md)。分页兼容修复后已在最终候选 APK 上重新执行上述检查。
