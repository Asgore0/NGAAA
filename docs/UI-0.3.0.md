# 0.3.0 UI 与验收记录

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

日期：2026-10-18，Asia/Shanghai。根据本轮反馈重做布局与外观，以单手触达、清晰阅读和稳定切换为目标。

## 本轮设计

- 顶部 56 dp，仅保留标题、菜单、搜索与消息等操作，点击范围至少 48 dp。
- 首页“关注 / 推荐 / 热帖 / 活动”下移，独立占 48 dp，位于主导航上方；选中态使用圆角实色胶囊。
- 主导航 64 dp，图标与 12 sp 文字纵排：“首页 / 版块 / 评分 / 我的”。
- 标题栏、正文、分组和主导航采用线性布局；底栏占用自己的空间，不覆盖正文。
- 暖白与柔和深色；推荐首页为精选首卡和图文列表，标题分别为 18 / 16 sp；取消密集双列小字。
- 首页各分组保留进程内滚动位置，版块页保留搜索词、分类与列表位置；数据使用 5 分钟内存缓存，提供明确刷新入口。
- 取消整页上浮和回弹；菜单改为按内容高度展开的底部面板，玻璃只在菜单背景可选。
- 正文配色、系统栏和对话框与浅深主题一致。

## 实际测试结果

环境：本任务独立 Android Emulator 37.2.12、Android 15 / API 35 Google APIs arm64-v8a rev9、1080×2400、420 dpi。本轮使用专用 UI 验收 AVD，保留已有本机账号测试数据；会话文件不进入交付包。

| 步骤 | 实际结果 |
| --- | --- |
| 安装与启动 | 最终 0.3.0 包覆盖安装并启动成功，同本地签名支持升级。 |
| 底部分组 | 推荐、活动、关注与热帖均可切换，选中态与内容对应；顶部不再保留这四个分组。 |
| 滚动恢复 | 滚动推荐，切到热帖再回推荐；14 个可见文本及屏幕坐标完全一致。 |
| 缓存与刷新 | 分组切换复用已载入内容；显式刷新入口可触发重新读取。网络请求在缓存锁之外，不持锁阻塞主线程。5 分钟失效逻辑经静态检查，未做单独计时验收。 |
| 底栏与正文 | 正文视口止于底部分组之上，分组和主导航分别占位；列表可滚动到末尾。 |
| 搜索与键盘 | 输入 IT 后过滤出对应版块；软键盘弹出时主导航隐藏，收起后恢复；切去首页再回版块仍保留 IT。 |
| 深浅色 | 暖白和柔和深色首页已实际切换并截图，导航和卡片文字可读；不据此宣称完整无障碍合规。 |
| 紧凑菜单 | 打开、关闭和深色开关可用；高度按菜单内容计算，已修复材质背景导致的大块下方空白。 |
| 评分与个人页 | 从新版底部入口进入真实评分列表与个人页；菜单、设置均显示已有登录状态。 |
| 会话与签到设置 | 最终升级后仍已登录、自动签到保持开启，页面保留今天已签到状态。没有重新索取密码或 Cookie。 |
| 回归与构建 | 165 项正文 + 41 项 API + 15 项评分，共 221 项检查通过；lint 0 错误 / 1 个官方 WebView JavaScript 警告；APK V2/V3 签名及 zipalign 通过。 |
