# 0.7.0 原生功能与验证范围

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

日期：2026-10-18。Android 最低 API 26，编译与目标 API 35。

0.7.0 将阅读、账号授权、编辑器和社区核心页面改为 Android 原生控件。应用没有 WebView、内嵌官方网页、广告 SDK 或统计 SDK。正文中的普通外链可在用户确认后交给系统浏览器；未支持的 NGA 链接会明确提示，不以打开官方页面代替原生功能。

这是第三方客户端，仍有功能与界面差异，不代表 NGA 全部功能已经完成，也不承诺官方 UI 逐像素 1:1。

## 写操作和验证边界

- 本轮没有实际发帖、回复、引用发布、编辑服务器帖子、上传文件、发送/回复私信或修改云端收藏。
- 发布和上传由用户明确选择、查看确认内容后触发；接口只有在服务端明确确认后才返回成功。
- 断网、跳转或无法识别的写入响应属于“结果未确认”。应先检查服务器记录，再决定是否重新操作，不能自动重发。
- 验证码、短信、人机验证或其他安全挑战会明确阻止操作；当前没有原生挑战答题或验证绕过流程。
- 投票、评分配置、直播、版主管理和 NGA 的全部高级功能尚未覆盖。未支持状态应显示具体限制，不能伪造成功或空列表。
- 私信最后一页缺省 nextPage 的结构已修复，最终 APK 已重新读取通过；自定义收藏夹目录仍返回服务器错误，默认云端收藏可以独立读取。

此前 [0.2.0 账号/签到记录](EMULATOR-VALIDATION.md) 含历史 WebView 登录流程，属于旧版证据，不表示 0.7.0 仍含 WebView，也不证明新原生扫码登录已完成正向验收。
