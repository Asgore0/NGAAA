## 自动云端收藏

每次冷启动、登录或身份变化后自动核对当前账号收藏。返回前台时按60秒新鲜度节流，仍有待同步记录则优先处理。收藏/取消先持久保存，再由进程内单线程队列提交并回读确认；写入与下载共用队列，快速反复点击保留最后revision。

前台网络恢复触发重新核对，临时失败按3/10/30/60秒有限退避；重新进入前台可开始新的临时重试周期。登录、安全验证、权限和限流拒绝停止自动重试，待处理选择仍保留。用户无需每次按同步；备用“立即同步”可主动核对。

完整host/账号/Cookie约束每个请求，预读、写入和回读期间更换凭据不会借用新Cookie继续旧任务。账号范围的云端快照合并保留待同步取消记录和旧版未上传的本地收藏，不自动批量上传旧数据。

收藏页自动更新列表、数量、星标及状态，不重建整页；首页收藏数量和关注列表也接收更新。弱观察者和前台token随Activity清理，页面重建不产生并行写队列，后台不持续轮询。

## 验证

专用API35模拟器先移除本地17个已知云端收藏副本，正常强停重启后自动拉回，再以探针启动任何Activity前的持久状态及独立云端读取核对。生产星标添加/取消不点同步，服务器往返匹配。真实关闭专用AVD Wi-Fi和移动数据后点收藏，待操作持久保存；恢复网络并正常重启后自动完成。六阶段669断言、10次独立读取通过。

额外真实界面两次星标操作确认自动更新；收藏页取消前后generation保持2，列表消失、云端数量18回到17，无手动同步。360dp浅色和840dp深色两张公开筛选截图逐张复核。完整云端集合、本地收藏/图标、账号、显示及网络设置恢复；登录和既有签到记录保留。
