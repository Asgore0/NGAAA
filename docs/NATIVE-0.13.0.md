# Android 0.13.0

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

根据0.12.0实装反馈，改善胶囊快速来回切换的跟手感、拉伸融合与松手衔接，并补齐版块原图、修复用户头像格式和加载行为。versionCode14，沿用包名与签名。17组离线与44项设备检查通过，约56.6秒原始录屏已解码并完成抽样目视QA。

## 胶囊与页面切换

- 拖动、尾部形变和松手收敛保留当前状态与速度；拖动松手不再重复捕获缓动，远距离点按仍保留短意图渐变，避免首帧跨过多个标签。
- 缩短旧方向速度记忆，提高跟随与融合速度；视觉中心更靠近手指，临近边缘平滑收敛。脖颈和厚度连续，反向不切换两套轮廓。
- 回放Android批量历史触点，忽略已消费旧样本；水平手势建立时接续当前胶囊位置，重抓不套用早先DOWN位置。保留多指、尺寸变化、辅助功能和减少动画设置。
- 页面合并提交静默窗口由72 ms缩短到32 ms；胶囊动画不等待页面重建。高光更快跟随，不增加背景采样频率。

模型验证覆盖20类连续性场景和12条拖动、6次松手、2次停住轨迹，快速反向平均误差较0.12模型下降约50–66%，松手轮廓收敛约296–330 ms。另在同一模拟器、boot、驱动、单元格几何和直接对齐的时间基准下完成4项真实输入对照：快速反向平均偏差下降约35–48%，p95下降约47–52%，慢拖平均下降约61–69%。实际对照衡量原生帧几何，不是物理触控延迟或固定帧率。定义与数值见 [验证总览](VALIDATION.md)。

## 版块图标与用户头像

旧版官网小图映射只覆盖373个原有唯一fid中的97个；此次核验官方Android原图端点，覆盖352个fid，新增255个，其余21个保留文字占位。536张核验原PNG共约5.56 MB，生产352个fid映射及全部PNG的Android分批解码已通过，网络请求0。精确官方URL优先映射本地资产，缺失时尝试对应CDN；研究下载未使用Cookie，来源和SHA保存在资产清单。

184张为合集独立资产。当前目录仍按fid去重，合集身份和路由尚未接入，不将资产数量计作当前列表新增覆盖，也不借父版块图冒充合集图。

用户头像补充官方多候选、编码分隔符与紧凑地址，避免空用户表覆盖同响应已有头像。只有可见视图订阅；离屏、隐藏、重绑和分离取消，队列繁忙重试。同UID共享工作与缓存，匿名和负数ID不查。

本次排查确认，正常已登录资料页可显示真实照片，而4名正数公开作者的无Cookie查询都返回空头像。因此补齐改为使用当前登录态：主Activity提供host和Cookie的不可变快照，GET仅发往当前受信NGA站点（bbs.nga.cn、ngabbs.com、nga.178.com），不跟随重定向；响应和读取全程检查会话仍相同。账号/站点范围变化重建解析器，取消旧任务并清理缓存。未登录使用公开无Cookie来源；CDN图片与本地图标不携带Cookie。仅提取匹配UID的头像，不保存其他资料或响应正文。

登录态补齐是用户头像缺失的主要修复。AvatarLiveProbe已从公开楼层选择3名已知有真头像的正常作者，用生产来源、全新元数据/图片缓存和可见空元数据绑定，3/3补齐并解码真实照片；默认图和不匹配计数0，无mock、截图或远端写入，原页已恢复，账号与设置保持一致。仍无可用个人头像时才显示官方通用头盔，标记“默认头像”，不计作个人头像覆盖，也不保证每位作者都有个人头像。
