# NGAAA 0.20.1 UI 审查与自适应修复

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

版本 0.20.1，versionCode 35。沿用 0.20.0 包名与签名，可覆盖安装并保留本机数据。

## 已复现问题与修复范围

- 窄窗口下，工具栏次要操作移入更多菜单，保留返回和可读标题。收藏版块入口、快捷菜单、关注和社区分页允许内容决定行高，避免大字号裁切。
- 板块目录分类与阅读页底部页码按实际可用宽度排布。目录空间不足时拆分操作行；阅读底栏空间不足时将收藏和回复放入更多菜单，分页仍可直接操作。
- 跳页快捷按钮按文字与宽度重新分行，长页码输入适应窄窗。登录方式、扫码确认与刷新、密码和短信登录按钮、编辑工具与附件恢复操作按内容测量，二维码卡片使用所在窗格的实际宽度。
- 原生正文普通附件独占一行，保留表情随文字行内显示。字号标记应用于原生文字，嵌套范围以内层字号为准，保留链接、加粗与颜色。

## 验证方式与限制

先在本轮专用模拟器中捕获基线截图，再对相同生产组件运行离线合成数据与尺寸测量。测试辅助包使用独立 UID、没有网络权限，不读取主客户端账号，不向社区发布、发信或投票。真实客户端验证采用公开页面只读浏览及可取消弹窗。

最终通过项目、失败尝试、候选 APK 与源码绑定、截图和原始录屏以单独交付报告为准；此文不把计划中的测试写成已通过。窗口宽度和字号测试不等同实体折叠屏铰链测试，截图与录屏不证明所有设备的帧率。

黑金图标及 GlassPanel、LiquidSelection、LiquidMotion、Motion 四个核心保持 0.20.0 文件字节，不恢复页面背景采样。
