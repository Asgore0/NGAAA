# NGAAA 0.20.7

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

Android 原生客户端，versionCode 41，沿用同一包名与签名，可覆盖安装。

## 会话检查的重复开销

主题列表图片、楼层按钮、目录收藏和头像回调需要确认当前页面仍属于同一登录会话。此前每次检查都会访问 Android Keystore 解密 Cookie、解析账号，再计算 SHA-256；多行内容会重复执行这些工作。

现在每个 NgaStore 实例最多保存一份 UI 会话摘要。每次使用仍同步读取当前线路与权威加密凭据，任一发生变化就重新计算，因此同一账号更新登录令牌、切换账号、切换线路、退出以及其他实例写入都会即时失效。缓存只保留加密来源、派生摘要和状态，不保留明文 Cookie 或 UID。

解密失败、来源在计算期间发生变化、来源超出预算等结果不进入缓存。前后台切换、内存回收和销毁会清空界面使用的缓存。已成功命中的 UI 摘要不会再次访问 Keystore；密文不变时的 Keystore 可用性变化，在生命周期清理或实际凭据读取时才会被观察。网络请求仍通过原有路径捕获真实登录信息。

## 头像滚动与重试

已经显示的静态头像和没有图片来源的占位项不再随每次滚动反复遍历父视图计算可见区域。等待同一重试截止时间的头像只保留一个定时任务，避免不断删除、重新加入主线程消息队列。

尚在加载的头像仍检查可见性；离屏、解绑与重绑会取消原请求，旧回调不能覆盖新头像。

## 验证范围

同一源码的独立 UID、无网络权限设备探针使用合成账号与真实 Android Keystore，比较旧版和新版 UI 会话检查，并验证同步失效、跨存储实例写入和临时 Keystore 失败后的恢复。头像探针使用真实 View 计算祖先可见性调用及方法追踪中的定时任务调度次数；方法追踪耗时不作为速度或 FPS 结论。

另在实际客户端只读浏览公开板块，检查列表滚动、图片预览和快速返回，并记录 gfxinfo 与模拟器录屏。公开内容、网络、模拟器和宿主调度会影响耗时，测试结果不等于所有实体设备的表现。本轮未重新执行真实账号登录、签到或社区写入。
