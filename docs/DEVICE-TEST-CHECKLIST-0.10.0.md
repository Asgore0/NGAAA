# 0.10.0 设备检查

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

设备为本任务专用Android35模拟器。覆盖升级、登录按钮轮询、三种原生登录入口、官方验证码加载、头像及点赞、收藏、菜单、回复定位和公开页面录屏均由实际界面或固定脱敏探针检查。

窄屏与展开尺寸通过临时改变同一模拟器显示尺寸检查，测试后恢复原尺寸；不是物理折叠铰链测试。

账号密码/短信成功路径仅有合成协议测试，未使用真实密码或发送短信。本版未重新扫码授权。后台任务的强制触发也不能代表自然24小时或厂商后台。

最新布尔检查、安装包哈希、源文件哈希和限制见 设备实证（历史附件未收入源码仓库）。
