## 录屏与交付状态

原始未剪辑录屏（历史附件未收入源码仓库） 长 24.2868 秒、3952646 字节，已解码并目视核验八帧。视频 SHA-256：

`19a977a45a7bca24238a8015bdfd72c301b3d871f51b9e121966f0c820cf652a`

录屏结束后再次核对最终安装字节、`loggedIn=true`、首页单层导航及零 WebView。

**本版新二维码授权至保存的完整正向流程仍待手机 grant。** 十分钟是本机恢复上限，不是 NGA 服务端有效期；进程在响应或提交落盘前结束仍可能丢失最新进度。清理失败的密钥失效是尽力处理，不等于磁盘事务或跨重启永久删除。

APK、源码 ZIP、预览与录屏的大小及 SHA 见 发布元数据（历史附件未收入源码仓库） 和 校验清单（历史附件未收入源码仓库）。源码清单包含全部允许交付文件，排除密钥、账号存储、QR 资料与诊断工作目录。

本轮没有实际发布/修改帖子、上传附件、发送私信或增删云端收藏。自然跨日签到、API26/31、厂商真机、更多屏幕和完整无障碍仍待覆盖；验证码、短信、投票及管理等高级功能尚未全部实现。
