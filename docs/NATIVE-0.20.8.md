# NGAAA 0.20.8

> 历史／来源文档：保留原版本的实现说明和验证边界，不代表当前候选重新验收。原始设备附件未随源码公开；当前状态见[文档索引](README.md)。

本版继续处理首次进入板块、长帖滚动和图片加载路径的重复工作，Android 原生界面与固定玻璃材质保持现有交互。

## 变更

- 每次构造页面的屏蔽规则只捕获一次真实登录会话，本机和云端规则使用同一 host/account。下一次构造仍读取最新规则；不新增跨页面凭据缓存。
- 帖子列表同一标题只做一次 HTML 清理，标题和图片预览共用结果。子版块批量构造在一次同步循环里共用收藏状态，事件发生时仍检查当前账号与收藏状态。
- 同一正文节点中的图片在一次同步滚动/布局回调内共用可见区域与祖先裁剪信息；每张图片仍独立计算文本行和横向边界。异步图片、动画和下次滚动重新采样，不跨帧复用坐标。
- 忙碌图片的同一重试截止时间只排一个任务；保持原有重试上限、离屏取消、320dp 预取、640dp 外释放和动画可见性限制。
- 位图超过整个 8 MiB 内存缓存预算时直接交付当前页面，不送入 LRU，避免把已有头像和缩略图连同自己全部逐出。图片本身的显示、采样上限和生命周期不变。
- 磁盘图片缓存已知文件长度时直接读入结果数组，省去 ByteArrayOutputStream 的第二份压缩字节副本。仍检查大小、EOF、文件增长、中断、链接和缓存世代。

## 验证方式与边界

离线测试覆盖账号/host 切换、屏蔽规则立即更新、媒体缓存准入、文件边界及取消；设备测试使用未修改的完整产品 JAR 和 APK 哈希绑定的独立测试包，真实 Android Keystore、LRU、解码器和文本排版，无网络权限，不读取客户端账号。

真实客户端另测试公开板块首次开页、列表及多楼层帖子滚动、图片预览、快速返回，并录屏。具体通过项、测量原始值、APK 哈希和视频均以随版本发布的审查报告为准。合成计数说明重复工作减少，不代表所有设备/网络下的帧率或完整开页耗时；模拟器结果不替代真机与物理折叠铰链测试。

独立 nativecontent 编译脚本补入此前遗漏的现有 AppPalette 源码依赖；不改变产品实现。
