## 常用功能

- 跨正常退出/重开继续阅读页码与楼层；历史、本地收藏的筛选、长按管理与确认清空；历史记录开关。
- 接收 Android 系统文字分享、手动粘贴 NGA 链接，多目标原生选择；全站/版内搜索、最近关键词及范围恢复；版块 ID、负数 ID 与合集入口。
- 楼层正文/原始代码/定位链接复制、系统分享；原生字号预览，以及媒体缓存统计和选择性清理。
- 版块、子版块、主题合集、原生帖子与图片查看；版块星标收藏和取消后自动同步 NGA 云端，启动与回到前台时自动核对云端收藏。
- 原生二维码、用户名/UID与密码、手机验证码登录；需要时单独显示 NGA 官方安全验证码。支持扫码后确认登录、授权恢复与账号身份补充。
- 原生发帖、回复、引用、编辑本人内容、附件上传、预览、草稿和提交结果不确定时的防重复保护。
- 独立点赞与点踩按钮，分别显示服务端明确返回的支持/反对总数；未知数量显示“—”。原生点赞/点踩与撤销、举报、只看楼主、普通投票与铜币投注；公开写操作有明确确认，不以本地动画假报服务器成功。
- 原生主题评分详情、评分输入、回复同时评分及修改本人评分回复；评分项目和范围由服务器提供，评分草稿随页面重建恢复。
- 用户资料的主题/回复分页、回复精确定位、头像补全；单条权限不足时保留其余可读条目。
- 原生关注/取消关注、关注用户动态、NGA 云端屏蔽用户与关键词，以及单独保留的本机屏蔽。
- 原生头像选择与裁切、签名编辑、主题/单层回复云收藏、收藏夹选择与创建、名称/默认/公开选项修改和删除。移除收藏明确绑定当前收藏夹并核对结果。
- 原生私信会话、回复、新私信与草稿；可按完整用户名查找、核对并选择收件人。最终发送前确认。
- 可选的 Android 后台未读通知，定期读取回复提醒和私信未读状态；默认关闭，用户开启并授予通知权限后生效。首次建立基线，不把历史未读都当新消息通知。
- 原生直链音视频播放器、可横滑表格、密码加密内容本机解密与骰子显示；代码块、引用、折叠和常用 NGA 标签原生排版。普通文字中的过多空白行压缩，代码空白保留。
- 一层液态玻璃底部胶囊、连续快速切换与手势动画、统一原生玻璃弹窗、深色、大字、窄屏和展开窗口适配；通过设备 WindowManager Extensions 避让分隔铰链。

## 平台与内容边界

本项目与 NGA 官方无隶属关系。外部活动和第三方网页内容会明确显示链接并确认后交给系统浏览器；官方活动页来自真实 Android 活动接口，没有用标题关键词伪造活动目录。腾讯安全验证仍使用官方控件的独立 WebView。

媒体直链可用平台播放器播放，实际格式和编解码支持由 Android 设备决定；第三方网站的视频页面不能等同于直链。Spine 旧版骨骼动画仍为明确的特殊内容边界，未捆绑许可条件未满足的 Spine 运行时，也未用静态图冒充动画。普通账号的本人编辑以服务器权限为准；没有向普通用户开放官方仅版主可用的整帖删除/抽楼管理接口。

后台签到与未读检查由 Android 调度，省电限制可能延迟。未读通知为至少 15 分钟周期的系统任务及前台补查，不承诺实时厂商推送。今日签到只在 NGA 明确确认后记录完成。

## 本地构建和验证

Java17 与 Android SDK API35 / build-tools35.0.0 就绪后运行：

```sh
bash build-local.sh
```

构建不需要 Gradle 或下载 Android 运行时依赖。签名密钥保存在源码工程之外；发布更新使用同一签名，源码包不含密钥、账号、Cookie、官方 APK 或扫码授权数据。自行使用新密钥构建的版本不能直接覆盖安装其他签名版本。

`tests/` 含协议、解析、持久化、导航、动画和界面策略回归；`tests/device/` 为需明确选择的 Android 验证器，不随客户端打包。测试专用 JSON 库使用固定校验和，不作为应用运行时依赖。

验证区分真实只读接口、独立 UID 且无网络权限的合成流程、Android 平台组件执行，以及窗口尺寸与合成铰链检查。常用功能列表是累计支持范围，不表示本版把所有功能都重新做过线上端到端实测；本轮没有用真实社区写入制造验收结果。当前验证报告随安装包单独提供。
