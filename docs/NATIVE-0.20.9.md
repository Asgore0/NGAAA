## 表情实体

普通正文中的有效十进制/十六进制非 ASCII 数字实体（例如 `&#128517;`、`&#x1F605;`），以及服务端恰好一层 `&amp;` 包裹的数字实体（例如 `&amp;#128517;`）还原为 Unicode 字符，支持补充平面、肤色、变体选择符和 ZWJ 组合。严格单遍、有界扫描，不递归解码；无效值、代理项、控制字符不转换为 Unicode。ASCII 语法实体、BBCode token 参数和代码段保留原有语义，编码 HTML/BBCode 不会变成活动控件或链接。普通未配对方括号不会抑制后面的表情；真正未闭合代码段仍是原文。

[公开帖子 47764699 的第 16 楼](https://bbs.nga.cn/read.php?tid=47764699&pid=885545160) 在官方接口实际返回了 `&amp;#128517;`；仅支持直接数字实体会在真实正文中继续漏出代码。因此加入上述一层服务端包裹兼容，实体专项同时包含该楼公开原句。更深的 `&amp;amp;#128517;` 仍按原具名实体规则得到字面 `&amp;#128517;`，不会继续展开；代码段里的数字实体保留原文。Android 原有正文首尾空白整理行为保持不变。

## 首次进入板块

- 内置目录的分类、分组名称提升到各自循环外清理；空串不再调用 HTML 解析；每条简介只处理一次。目录顺序、名称、别名、分类与搜索元数据不变。
- 新开的板块先显示原生加载页，在页面读取线程捕获真实会话并校验导航时的账号范围，再请求新内容；响应后用同一会话准备屏蔽规则，规则就绪后才显示主题。缓存返回仍检查最新过滤规则，保留即时返回行为。
- 云屏蔽刷新与响应交错时，通过规则修订号重新读取过滤结果，不重发已经成功读取的主题请求。
- 论坛与子版块星标在后台合并读取已提交收藏快照。未就绪时暂不可操作；页面、账号和收藏修订号全部匹配才更新。收藏写入、回滚与云端确认的原有锁和顺序不变。
- 最近访问和阅读位置的排队写入在 UI 线程读取 volatile epoch，不再为取 epoch 等待后台写盘锁；写入与清空仍在原锁内核对 epoch，清除之前排队的记录不会复活。

## 验证与限制

设备探针以完整未改写生产 JAR/APK 绑定，独立 UID，无 INTERNET 权限；使用实际 Android 文本与 MainActivity，合成账号和本机假传输。目录比较全部公开字段；论坛记录程序导航、请求、响应结束与真实窗口 OnDraw 的时间。锁竞争使用受控 600ms 占锁，不能解释为实际用户磁盘耗时；OnDraw 不是 GPU 呈现或物理触摸时间。正常 0/120ms 响应另外测量。

真实客户端另验证公开帖子表情、首次开板块、列表/长帖滚动、图片和快速返回，附原始录屏。具体测量与通过项以随版本报告为准；不保证所有网络/设备下完全没有延迟。实际云端收藏写操作并非本轮测试目标，隔离探针验证状态、失败和账号边界。
